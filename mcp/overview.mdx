## What is MCP?

The **Model Context Protocol (MCP)** is an open standard that enables AI applications to securely connect to external data sources and tools. Think of MCP like a USB-C port for AI applications — a standardized way to connect AI apps to different services.

With MCP, you can give AI agents like Cursor or Claude Code access to Shanone's tools, integrations, and saved Skills through a unified interface — directly from your IDE or terminal.

## Supported Transport

Shanone MCP Server is a **remote, hosted MCP server** that speaks **Streamable HTTP**. There's nothing to install — your client connects directly over HTTPS using your Shanone API key.

| Transport | Status | Description |
|-----------|--------|-------------|
| **Streamable HTTP** | Recommended | Remote server hosted by Shanone at `/api/v1/mcp`. Just add a URL and an API key — no local process to install or keep running |
| **stdio** | Supported (local, optional) | For clients that can't speak remote HTTP MCP yet, Shanone also publishes a local stdio bridge (`@duzzle/Shanone-mcp` on npm) that proxies the same tools over your existing API key |
| SSE | Not supported | Server-Sent Events |

<Note>
The remote Streamable HTTP server exposes exactly the same tools as the local stdio bridge, so you can switch between them without changing how you use Shanone from your agent.
</Note>

## Supported Clients

Any MCP client that supports the Streamable HTTP transport (with custom headers for authentication) can connect to Shanone. Shanone officially documents setup for:

- **Cursor** — AI-powered code editor
- **Claude Code** — Anthropic's coding agent CLI
- **Codex** — OpenAI's coding agent CLI

<Note>
Clients that only support the stdio transport (or don't yet support custom HTTP headers) can use the local `@duzzle/Shanone-mcp` package instead — see the [Setup Guide](/mcp/setup) for details.
</Note>
