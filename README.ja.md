## Shanoneについて

Shanoneは、Cursor・Claude Code・その他の[MCP](https://modelcontextprotocol.io/)対応クライアントといったエージェントハーネスのための、ホスト型MCPサーバー + ツールベンダー + スキルベンダー + 権限管理プラットフォームです。140以上の連携(現時点で269以上を実装済み)を少数のメタツール経由でツールとして提供し、ユーザーは再利用可能なワークフローを「Skill」として保存でき、チームは誰がどのツールを使えるかをIAM的に細かく制御できます。
