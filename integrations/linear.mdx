# Linear

Shanone's Linear integration gives your agent 45 tools for issue tracking, project and cycle management, initiatives, and documents.

## Getting Started

<Steps>
  <Step title="Connect via OAuth">
    Ask your agent to do something with Linear (e.g. "create an issue for this bug"), or connect proactively from **Integrations** in the Shanone dashboard.
  </Step>
  <Step title="Authorize workspace access">
    Approve Linear's OAuth consent screen for the workspace you want Shanone to act on.
  </Step>
  <Step title="Retry your request">
    Once connected, `shanone_execute_tool` calls for `linear_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="linear_create_issue fails with a team/workflow state error">
    Linear issues require a valid `teamId` and, in some workflows, a valid state ID. Call `linear_list_teams` and `linear_list_workflow_states` first to get valid values, or check `shanone_get_tool_schema` for `linear_create_issue`.
  </Accordion>
  <Accordion title="Can't find an issue by its human-readable identifier (e.g. ENG-123)">
    Use `linear_search_issues` with the identifier as the query, or `linear_list_issues` filtered by team — `linear_get_issue` expects Linear's internal issue ID, not the short identifier, unless the tool schema indicates otherwise.
  </Accordion>
</AccordionGroup>
