# Amplitude

Shanone's Amplitude integration gives your agent 62 tools covering analytics queries, user/event taxonomy management, cohorts, annotations, and privacy/deletion requests.

## Getting Started

<Steps>
  <Step title="Get your Amplitude API credentials">
    In Amplitude, go to your project's **Settings > Projects** and copy the API Key and Secret Key.
  </Step>
  <Step title="Connect in Shanone">
    Ask your agent to do something with Amplitude (e.g. "show retention analysis for the last 30 days"), or add both keys proactively from **Integrations** in the Shanone dashboard.
  </Step>
  <Step title="Retry your request">
    Once both keys are stored, `shanone_execute_tool` calls for `amplitude_*` tools will succeed.
  </Step>
</Steps>

<Note>
Amplitude uses API key authentication rather than OAuth, and Shanone requires both the API Key and Secret Key together — most endpoints need the pair for HTTP Basic auth.
</Note>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Any amplitude_* call fails with a 401/403">
    Amplitude requires both the API Key and Secret Key to be connected — a single key isn't enough for most endpoints. Check **Integrations** in the Shanone dashboard for both values.
  </Accordion>
  <Accordion title="amplitude_get_funnel_analysis or amplitude_get_retention_analysis returns unexpectedly empty results">
    Double-check the event names against `amplitude_get_event_types` — Amplitude event names are case-sensitive and must match exactly what was ingested.
  </Accordion>
  <Accordion title="amplitude_check_cohort_status stays in a pending state">
    Cohort downloads and syncs are processed asynchronously by Amplitude; poll `amplitude_check_cohort_status` periodically rather than expecting an immediate result from `amplitude_request_cohort_download`.
  </Accordion>
</AccordionGroup>
