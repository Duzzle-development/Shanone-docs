# Browserbase

Shanone's Browserbase integration gives your agent 63 tools for headless cloud browsers — session and context management, low-level page actions (click, navigate, screenshot), higher-level browser agents, and serverless functions that run inside a browser context.

## Getting Started

<Steps>
  <Step title="Get a Browserbase API key">
    In the Browserbase dashboard, go to **Settings** and copy your API key (and optionally your Project ID).
  </Step>
  <Step title="Connect in Shanone">
    Ask your agent to browse a page or run a browser task, or add the API key proactively from **Integrations** in the Shanone dashboard.
  </Step>
  <Step title="Retry your request">
    Once the key is stored, `shanone_execute_tool` calls for `browserbase_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="browserbase_page_click or browserbase_page_input can't find the target element">
    Call `browserbase_page_get_elements` first to get up-to-date selectors — dynamic pages can re-render elements between actions, invalidating stale selectors.
  </Accordion>
  <Accordion title="browserbase_run_agent takes a long time to return">
    Agent runs are asynchronous; use `browserbase_wait_for_run` to block until completion, or poll `browserbase_get_run` if you need to do other work in between.
  </Accordion>
  <Accordion title="A file downloaded during a session doesn't show up afterward">
    Use `browserbase_list_downloads` for that session to retrieve the download reference, then `browserbase_get_download` — downloads aren't automatically persisted outside the session's artifact storage.
  </Accordion>
</AccordionGroup>
