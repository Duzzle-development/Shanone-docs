# Google Chat

Shanone's Google Chat integration gives your agent 49 tools covering spaces, messaging, membership, and the less common surfaces (availability status, custom emoji, read state, sections) that most integrations skip.

## Getting Started

<Steps>
  <Step title="Connect via OAuth">
    Ask your agent to do something with Google Chat (e.g. "post a summary to the #launch space"), or connect proactively from **Integrations** in the Shanone dashboard.
  </Step>
  <Step title="Authorize the Google account">
    Approve Google's OAuth consent screen for the account you want Shanone to act on.
  </Step>
  <Step title="Retry your request">
    Once connected, `shanone_execute_tool` calls for `google_chat_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="google_chat_create_message fails when trying to send a rich card">
    Use `google_chat_create_card_message` instead of `google_chat_create_message` for card-formatted content — the plain message tool only accepts text.
  </Accordion>
  <Accordion title="google_chat_search_messages doesn't find an older message">
    Search indexing can lag for very recent messages, and search only covers spaces the connected account is a member of — verify with `google_chat_list_spaces` first.
  </Accordion>
  <Accordion title="google_chat_upload_attachment succeeds but the file doesn't appear in the message">
    Attachments must be referenced in a follow-up `google_chat_create_message` call using the returned attachment resource — uploading alone doesn't post it to the space.
  </Accordion>
</AccordionGroup>
