# Monday.com

Shanone's Monday.com integration gives your agent 68 tools covering boards, items/subitems, columns, docs, groups, updates, and account/team administration.

## Getting Started

<Steps>
  <Step title="Connect via OAuth">
    Ask your agent to do something with monday.com (e.g. "list my boards"), or connect proactively from **Integrations** in the Shanone dashboard.
  </Step>
  <Step title="Authorize the workspace">
    Approve monday.com's OAuth consent screen for the workspace you want Shanone to act on.
  </Step>
  <Step title="Retry your request">
    Once connected, `shanone_execute_tool` calls for `monday_*` tools will succeed.
  </Step>
</Steps>

<Note>
If you'd rather not use OAuth, monday.com also accepts a personal API token (from **Admin > API** in your monday.com account) as an alternative credential in the same Integrations screen.
</Note>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Tool calls fail with a complexity budget error">
    monday.com's GraphQL API enforces a query complexity limit per minute — check `monday_get_query_complexity` and reduce batch sizes or add delays between heavy calls like `monday_get_items_page`.
  </Accordion>
  <Accordion title="monday_change_multiple_column_values fails with a format error">
    Column values must be JSON-encoded in the exact shape monday.com expects per column type; check `monday_list_columns` for each column's type before building the payload.
  </Accordion>
  <Accordion title="Can't find an item created moments ago">
    monday.com's search indexing can lag slightly behind writes — retry `monday_search_items_by_column_values` after a short delay, or fetch directly via `monday_get_item` using the ID returned from creation.
  </Accordion>
</AccordionGroup>
