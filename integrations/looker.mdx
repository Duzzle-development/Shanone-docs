# Looker

Shanone's Looker integration gives your agent 71 tools spanning ad-hoc querying, dashboard/look content management, conversational analytics, scheduled delivery, embedding, and admin operations.

## Getting Started

<Steps>
  <Step title="Create a Looker API3 credential">
    In Looker, go to **Admin > Users**, select the service account/user Shanone should act as, and generate an API3 client ID and secret.
  </Step>
  <Step title="Add the credentials in Shanone">
    Go to **Integrations > Looker** in the Shanone dashboard and enter your Looker instance's base URL, the client ID, and the client secret.
  </Step>
  <Step title="Retry your request">
    Once saved, `shanone_execute_tool` calls for `looker_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="looker_run_query times out on a large result set">
    Use `looker_create_query_task` plus `looker_get_query_task_results` for async execution instead of `looker_run_query`, which blocks until the query finishes.
  </Accordion>
  <Accordion title="looker_create_sso_embed_url fails with an invalid signature error">
    SSO embedding requires the embed secret configured in Looker's Admin > Embed settings to match what Shanone is signing with — double check the embed domain allowlist too.
  </Accordion>
  <Accordion title="Admin tools return a 403">
    User, role, and group management require the connected API3 credential to belong to a Looker user with Admin permissions — a viewer-level credential won't work for these calls.
  </Accordion>
</AccordionGroup>
