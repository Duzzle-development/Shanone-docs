# GitHub Copilot

Shanone's GitHub Copilot integration gives your agent 37 tools for admin/enterprise-facing Copilot management: seats, billing, usage metrics, custom agents, content exclusion, and Copilot Cloud Agent policies.

## Getting Started

<Steps>
  <Step title="Generate a fine-grained Personal Access Token">
    In GitHub, go to **Settings → Developer settings → Fine-grained tokens** and create a token with Copilot-related organization permissions.
  </Step>
  <Step title="Add it to Shanone">
    Open **Integrations** in the Shanone dashboard, select GitHub Copilot, and paste in the token.
  </Step>
  <Step title="Retry your request">
    Once saved, `shanone_execute_tool` calls for `copilot_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Enterprise-scoped tools return a 404">
    `copilot_get_enterprise_*` and `copilot_*_enterprise_agent_*` tools only work for organizations that are part of a GitHub Enterprise account — for a plain organization, use the `_org_` equivalents instead.
  </Accordion>
  <Accordion title="copilot_add_users or copilot_add_teams fails with a permissions error">
    Managing Copilot seats requires organization owner or Copilot admin permissions on the token's account; a token from a regular member can read usage but not modify seat assignments.
  </Accordion>
  <Accordion title="Metrics tools return an empty array for a recent date">
    GitHub Copilot usage metrics are aggregated with roughly a one-to-two day delay; very recent activity may not show up in `copilot_get_org_metrics_daily` yet.
  </Accordion>
</AccordionGroup>
