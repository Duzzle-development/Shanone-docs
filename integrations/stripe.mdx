# Stripe

Shanone's Stripe integration gives your agent 328 tools — the largest single integration in the catalog — covering everything from a basic charge to Stripe Treasury and Issuing.

<Warning>
Most Stripe tools can move real money or create real financial records. Review arguments carefully before asking your agent to execute anything beyond read-only queries, and consider connecting a restricted API key scoped to what your agent actually needs.
</Warning>

## Getting Started

<Steps>
  <Step title="Connect your Stripe account">
    Ask your agent to do something with Stripe, or connect proactively from **Integrations** in the Shanone dashboard.
  </Step>
  <Step title="Choose test or live mode">
    Stripe distinguishes test and live API keys entirely by which key you connect — connect a **test mode** key while building and verifying agent workflows.
  </Step>
  <Step title="Retry your request">
    Once connected, `shanone_execute_tool` calls for `stripe_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="A write operation succeeded but I don't see it in the Stripe Dashboard">
    Check whether you're looking at test mode or live mode in the Dashboard — it must match the mode of the API key that's connected.
  </Accordion>
  <Accordion title="Confirmation Required response">
    Higher-risk Stripe tools (e.g. issuing card actions, large refunds) may return `reason: "confirmation_required"`. Re-run with the same arguments plus `"confirm": true` once you're sure.
  </Accordion>
  <Accordion title="Object not found errors on IDs that look valid">
    Stripe IDs are mode-specific — a `cus_...` or `pi_...` ID created in test mode doesn't exist in live mode and vice versa.
  </Accordion>
</AccordionGroup>
