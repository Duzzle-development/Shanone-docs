# OneDrive

Shanone's OneDrive integration gives your agent 87 tools spanning everyday file management, SharePoint site access, and the Microsoft 365 governance tools (retention labels, sensitivity labels, delta sync) most integrations leave out.

## Getting Started

<Steps>
  <Step title="Connect via OAuth">
    Ask your agent to do something with OneDrive (e.g. "find the latest version of the Q3 budget spreadsheet"), or connect proactively from **Integrations** in the Shanone dashboard.
  </Step>
  <Step title="Authorize the Microsoft account">
    Approve Microsoft's OAuth consent screen for the account whose OneDrive and SharePoint sites Shanone should access.
  </Step>
  <Step title="Retry your request">
    Once connected, `shanone_execute_tool` calls for `onedrive_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="onedrive_upload_file fails for larger files">
    Microsoft Graph's simple upload endpoint tops out around 4MB. For anything larger, use `onedrive_create_upload_session` to start a resumable upload session instead.
  </Accordion>
  <Accordion title="onedrive_get_delta suddenly returns a resync-required error">
    Delta tokens can expire or be invalidated server-side. Call `onedrive_get_delta` without a token to restart the sync loop, then persist the new token from the response for subsequent `onedrive_get_delta_by_token` calls.
  </Accordion>
  <Accordion title="SharePoint tools return empty results or a 403">
    Most `onedrive_*` SharePoint tools require a specific site or drive ID — start with `onedrive_search_sites` or `onedrive_get_site` to resolve the right site, and confirm the connected Microsoft account actually has access to it.
  </Accordion>
  <Accordion title="onedrive_delete_file doesn't seem to free up space">
    Deleted items move to the recycle bin first. Use `onedrive_list_recycle_bin_items` to confirm, and `onedrive_permanent_delete` if you need to remove them for good.
  </Accordion>
</AccordionGroup>
