# Fireworks AI

Shanone's Fireworks AI integration gives your agent 96 tools spanning inference, model/LoRA management, on-demand deployments, fine-tuning (SFT/DPO), evaluations, and account administration.

## Getting Started

<Steps>
  <Step title="Get a Fireworks AI API key">
    Create an API key from the [Fireworks AI dashboard](https://app.fireworks.ai/settings/users/api-keys).
  </Step>
  <Step title="Add the key in Shanone">
    Open **Integrations** in the Shanone dashboard, select Fireworks AI, and paste the API key.
  </Step>
  <Step title="Retry your request">
    Once saved, `shanone_execute_tool` calls for `fireworks_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="fireworks_create_sft_job or fireworks_create_dpo_job fails to start">
    Verify the dataset finished uploading and validating first — use `fireworks_validate_dataset_upload` and check `fireworks_get_dataset` status before referencing it in a fine-tuning job.
  </Accordion>
  <Accordion title="fireworks_load_lora returns an error about deployment compatibility">
    LoRA adapters must be loaded onto a deployment running the exact base model they were fine-tuned from — check the base model on both the LoRA and the target deployment with `fireworks_get_lora` / `fireworks_get_deployment`.
  </Accordion>
  <Accordion title="Admin tools (fireworks_create_user, fireworks_update_account) return a permissions error">
    These require the connected API key to belong to an account admin, and some management endpoints additionally need an `account_id` configured — inference-only tools work without it.
  </Accordion>
</AccordionGroup>
