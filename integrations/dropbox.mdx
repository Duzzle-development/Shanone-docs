# Dropbox

Shanone's Dropbox integration gives your agent 166 tools spanning personal file operations, sharing, and the full team-admin surface (members, groups, folders, space limits) that most integrations skip entirely.

## Getting Started

<Steps>
  <Step title="Connect via OAuth">
    Ask your agent to do something with Dropbox (e.g. "share my Q3 report with the finance team"), or connect proactively from **Integrations** in the Shanone dashboard.
  </Step>
  <Step title="Authorize the Dropbox account">
    Approve Dropbox's OAuth consent screen for the account (or team) you want Shanone to act on.
  </Step>
  <Step title="Retry your request">
    Once connected, `shanone_execute_tool` calls for `dropbox_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="dropbox_upload_file fails on large files">
    Files above roughly 150MB need the chunked upload session flow — use `dropbox_upload_session_start`, `dropbox_upload_session_append`, and `dropbox_upload_session_finish` (or the batch variants) instead of a single upload call.
  </Accordion>
  <Accordion title="Team admin tools return a permission error">
    `dropbox_team_*` tools require the connected account to be a Dropbox Business/Team admin; a personal Dropbox account or non-admin team member cannot call them.
  </Accordion>
  <Accordion title="A shared folder operation returns an async job status instead of a result">
    Some sharing operations (like `dropbox_share_folder` or `dropbox_transfer_folder`) run asynchronously — poll `dropbox_check_share_job_status` or `dropbox_check_job_status` with the returned job ID until it completes.
  </Accordion>
</AccordionGroup>
