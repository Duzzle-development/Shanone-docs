# CircleCI

Shanone's CircleCI integration gives your agent 111 tools for CI/CD: pipelines, workflows, jobs, projects, contexts, policies, OIDC, and pipeline insights.

## Getting Started

<Steps>
  <Step title="Generate a Personal API Token">
    In CircleCI, go to **User Settings → Personal API Tokens** and create a new token.
  </Step>
  <Step title="Add it to Shanone">
    Open **Integrations** in the Shanone dashboard, select CircleCI, and paste in the Personal API Token.
  </Step>
  <Step title="Retry your request">
    Once saved, `shanone_execute_tool` calls for `circleci_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="circleci_trigger_pipeline returns a 404">
    `project_slug` must be in the form `vcs-slug/org-name/repo-name` (e.g. `gh/my-org/my-repo`). Use `circleci_get_project` to confirm the exact slug before triggering.
  </Accordion>
  <Accordion title="Context or environment variable tools return a permissions error">
    Managing contexts and their environment variables requires org-admin scope on the Personal API Token's account — a token from a non-admin user can read pipelines but not write secrets.
  </Accordion>
  <Accordion title="Insights tools return no data for a recently created project">
    CircleCI Insights aggregates data with a delay and only covers pipelines that have actually run; a brand-new or rarely-run project won't have summary data yet.
  </Accordion>
</AccordionGroup>
