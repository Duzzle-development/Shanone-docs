# Canva

Shanone's Canva integration gives your agent 36 tools for the Canva Connect API: designs, assets, folders, brand templates, autofill jobs, imports/exports, and comments.

## Getting Started

<Steps>
  <Step title="Connect via OAuth">
    Ask your agent to do something with Canva (e.g. "list my recent designs"), or connect proactively from **Integrations** in the Shanone dashboard. Either way, you'll get a `connect_link` to authorize Shanone's Canva app.
  </Step>
  <Step title="Authorize the Canva account">
    Approve Canva's OAuth consent screen for the account you want Shanone to act on.
  </Step>
  <Step title="Retry your request">
    Once connected, `shanone_execute_tool` calls for `canva_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="canva_create_design_autofill_job fails with a schema mismatch">
    The `data` payload's field names and types must exactly match the brand template's dataset — check `canva_get_brand_template_dataset` first to see the expected fields before calling autofill.
  </Accordion>
  <Accordion title="Export or import jobs stay in a pending state">
    Canva Connect API jobs (export, resize, import, autofill) are asynchronous. Poll the corresponding `_get_*_job`/`_get_export_status` tool until the status is `success` or `failed` rather than expecting an immediate result.
  </Accordion>
  <Accordion title="Uploaded asset doesn't appear in canva_list_assets right away">
    Asset uploads (`canva_upload_asset`, `canva_create_url_asset_upload_job`) are processed asynchronously — check `canva_get_asset_upload_job` / `canva_get_url_asset_upload_job` for completion before expecting the asset to be usable.
  </Accordion>
</AccordionGroup>
