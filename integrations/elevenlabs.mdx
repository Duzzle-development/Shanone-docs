# ElevenLabs

Shanone's ElevenLabs integration gives your agent 83 tools covering the full audio-AI surface — speech synthesis, voice design, dubbing, music generation, and transcription — not just basic text-to-speech.

## Getting Started

<Steps>
  <Step title="Get an ElevenLabs API key">
    Create an API key from [ElevenLabs settings](https://elevenlabs.io/app/settings/api-keys).
  </Step>
  <Step title="Add the key in Shanone">
    Open **Integrations** in the Shanone dashboard, select ElevenLabs, and paste the API key.
  </Step>
  <Step title="Retry your request">
    Once saved, `shanone_execute_tool` calls for `elevenlabs_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="elevenlabs_text_to_speech returns unnatural pronunciation for names or jargon">
    Add custom rules with `elevenlabs_add_pronunciation_dictionary_from_rules` (or upload a lexicon file) and attach the dictionary to your voice/request.
  </Accordion>
  <Accordion title="Dubbing or project conversion tools return "processing" instead of a final result">
    Dubbing and project/chapter conversion are asynchronous; poll `elevenlabs_get_dubbing_metadata` or `elevenlabs_get_project_snapshots` until status reflects completion before calling the download tools.
  </Accordion>
  <Accordion title="Voice cloning quality is poor">
    `elevenlabs_add_voice` quality depends heavily on clean, noise-free samples — run `elevenlabs_audio_isolation` on source recordings first to strip background noise before cloning.
  </Accordion>
</AccordionGroup>
