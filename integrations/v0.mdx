# V0

Shanone's v0 integration gives your agent 42 tools for driving Vercel's v0 AI UI generator — creating and iterating on chats, managing projects and deployments, and configuring MCP servers, on top of v0's newer v2 chat/message API.

## Getting Started

<Steps>
  <Step title="Create a v0 API key">
    Generate a key from [v0.dev/settings](https://v0.dev/settings).
  </Step>
  <Step title="Connect via API key">
    In the Shanone dashboard, go to **Integrations → V0** and paste the key (starts with `v0_...`).
  </Step>
  <Step title="Retry your request">
    Once connected, `shanone_execute_tool` calls for `v0_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Not sure whether to use v1 or v2 chat tools">
    `v0_v2_*` tools are v0's newer chat/message API with more creation options (from files, repo, or zip) and async variants. Prefer the `v0_v2_*` family for new integrations; the v1 `v0_create_chat`/`v0_send_message` family remains for existing chats created there.
  </Accordion>
  <Accordion title="v0_v2_deploy_chat or v0_v2_create_vercel_project fails">
    Both require a valid Vercel account link — run `v0_find_vercel_projects` or `v0_create_vercel_project_link` first to confirm the v0 account is connected to a Vercel team/project.
  </Accordion>
  <Accordion title="Async message/task tools never seem to finish">
    `v0_v2_send_message_async` and `v0_v2_resolve_task_async` return immediately with a task reference; poll `v0_v2_get_message` or the chat's message list rather than expecting the async call itself to block until completion.
  </Accordion>
</AccordionGroup>
