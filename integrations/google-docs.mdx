# Google Docs

Shanone's Google Docs integration gives your agent 58 tools across the full Docs API surface — content and formatting, tables, images, comments/suggestions, tabs, and the Markdown conversion tools that make agent-driven editing far more convenient than raw block manipulation.

## Getting Started

<Steps>
  <Step title="Connect via OAuth">
    Ask your agent to do something with Google Docs (e.g. "turn this outline into a formatted doc"), or connect proactively from **Integrations** in the Shanone dashboard.
  </Step>
  <Step title="Authorize the Google account">
    Approve Google's OAuth consent screen for the account you want Shanone to act on.
  </Step>
  <Step title="Retry your request">
    Once connected, `shanone_execute_tool` calls for `google_docs_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="google_docs_update_document_from_markdown produces unexpected formatting">
    The Markdown converter supports common elements (headings, lists, tables, bold/italic) but not every Docs-native feature — for advanced formatting, follow up with `google_docs_update_text_style` or `google_docs_update_paragraph_style` on the specific range.
  </Accordion>
  <Accordion title="Multiple edits in a row produce conflicting or overlapping changes">
    Index-based operations (insert/delete) shift subsequent content offsets — prefer a single `google_docs_batch_update` call with multiple requests over several sequential single-edit calls when making related changes.
  </Accordion>
  <Accordion title="google_docs_insert_comment or suggestion tools don't seem to take effect">
    Comments and suggestions are separate from content edits and require Docs' native commenting/suggesting permissions on the file — verify the connected account has at least commenter access.
  </Accordion>
</AccordionGroup>
