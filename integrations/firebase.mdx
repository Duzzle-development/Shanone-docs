# Firebase

Shanone's Firebase integration gives your agent 45 tools across the Firebase Admin surface — Firestore, Auth, Cloud Messaging, Remote Config, Cloud Storage, and app/project management.

## Getting Started

<Steps>
  <Step title="Create a service account key">
    In the Firebase console, go to Project Settings → Service Accounts and generate a new private key (JSON).
  </Step>
  <Step title="Add the key in Shanone">
    Open **Integrations** in the Shanone dashboard, select Firebase, and paste the full service account JSON.
  </Step>
  <Step title="Retry your request">
    Once saved, `shanone_execute_tool` calls for `firebase_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="firebase_query_firestore returns fewer results than expected">
    Firestore queries require indexes for compound filters/sorts — check the Firebase console for a missing-index error before assuming the query logic is wrong.
  </Accordion>
  <Accordion title="firebase_auth_delete_users silently skips some UIDs">
    Batch user deletion reports per-UID errors in its response; inspect the returned error list rather than assuming a 200-level success means every UID was deleted.
  </Accordion>
  <Accordion title="Tool calls fail with a permission or project-mismatch error">
    The service account JSON is scoped to one Firebase project — verify `firebase_get_project` returns the project you expect, since a key from the wrong project will fail on every subsequent call.
  </Accordion>
</AccordionGroup>
