# Stack Exchange

Shanone's Stack Exchange integration gives your agent 82 tools for searching questions, reading answers/comments/badges, browsing tags, and — for authenticated write access — posting questions/answers/comments and voting, across Stack Overflow and any other Stack Exchange site.

## Getting Started

<Steps>
  <Step title="Connect via OAuth">
    Ask your agent to do something with Stack Exchange (e.g. "search Stack Overflow for how to debounce a React hook"), or connect proactively from **Integrations** in the Shanone dashboard.
  </Step>
  <Step title="Authorize your Stack Exchange account">
    Approve the OAuth consent screen. You can optionally set an Application Key and a Default Site (e.g. `stackoverflow`) — the key raises your daily request quota from 300 to 10,000.
  </Step>
  <Step title="Retry your request">
    Once connected, `shanone_execute_tool` calls for `stackexchange_*` tools will succeed. Read-only tools work even without full OAuth if an Application Key is set.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Getting throttled or hitting a daily quota error">
    Without an Application Key, Stack Exchange limits you to 300 requests/day; set one on the integration to raise the limit to 10,000/day.
  </Accordion>
  <Accordion title="A search tool returns results from the wrong site">
    Most read tools take a `site` parameter (defaults to your configured Default Site) — pass it explicitly when querying a site other than Stack Overflow, e.g. `superuser` or `serverfault`.
  </Accordion>
  <Accordion title="Writing tools like stackexchange_create_answer or stackexchange_upvote_post fail">
    Write and vote actions require full OAuth authorization (not just an Application Key) and sufficient reputation on the target site — Stack Exchange enforces its own reputation thresholds for posting and voting independent of Shanone.
  </Accordion>
</AccordionGroup>
