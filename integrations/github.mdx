# GitHub

Shanone's GitHub integration gives your agent 176 tools — from everyday issue and PR workflows to CI/CD, code/secret scanning, org administration, and gists.

## Getting Started

<Steps>
  <Step title="Connect via OAuth">
    Ask your agent to do something with GitHub (e.g. "list open PRs in my-org/my-repo"), or connect proactively from **Integrations** in the Shanone dashboard.
  </Step>
  <Step title="Authorize the requested scopes">
    GitHub's OAuth consent screen shows the scopes Shanone requests (repo access, org read, etc.) — review and approve them.
  </Step>
  <Step title="Retry your request">
    Once connected, your agent's `shanone_execute_tool` calls for `github_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="403 or 404 on an org-level tool">
    Org-scoped tools (`github_list_org_secrets`, `github_get_org`, etc.) require the connected account to have the appropriate org role. Reconnect with an account that has admin access if these fail.
  </Accordion>
  <Accordion title="Workflow trigger succeeds but nothing runs">
    Confirm the workflow file actually declares a `workflow_dispatch` trigger — `github_trigger_workflow` can only start workflows that support it.
  </Accordion>
  <Accordion title="Secret/variable tools return empty values">
    GitHub never returns secret values over the API by design — `github_get_repo_secret` and friends only return metadata (name, timestamps), never the plaintext value.
  </Accordion>
</AccordionGroup>
