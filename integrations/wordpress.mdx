# WordPress

Shanone's WordPress integration gives your agent 42 tools for content management — posts, pages, media, comments, taxonomies, and users, via WordPress's built-in REST API.

## Getting Started

<Steps>
  <Step title="Generate a WordPress Application Password">
    In your WordPress admin, go to **Users → Profile → Application Passwords** and create a new password for Shanone. See [WordPress's Application Passwords guide](https://wordpress.org/documentation/article/application-passwords/) for details.
  </Step>
  <Step title="Connect via API key">
    In the Shanone dashboard, go to **Integrations → WordPress** and enter your site URL, username, and the Application Password.
  </Step>
  <Step title="Retry your request">
    Once connected, `shanone_execute_tool` calls for `wordpress_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Connection fails with a 401 even with a correct-looking password">
    WordPress Application Passwords are shown with spaces (e.g. `xxxx xxxx xxxx xxxx`) — some setups require the password exactly as displayed, including spaces; don't strip them when entering it in **Integrations**.
  </Accordion>
  <Accordion title="wordpress_create_post publishes immediately when I wanted a draft">
    Check the `status` field in the payload via `shanone_get_tool_schema` for `wordpress_create_post` — omitting it may default to `publish` depending on your WordPress configuration; set it explicitly to `draft`.
  </Accordion>
  <Accordion title="wordpress_delete_post or wordpress_delete_page only trashes instead of permanently deleting">
    By default WordPress moves posts/pages to trash rather than deleting them outright; check the tool's `force` parameter if you need permanent deletion.
  </Accordion>
</AccordionGroup>
