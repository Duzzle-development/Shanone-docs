# incident.io

Shanone's incident.io integration gives your agent 178 tools covering nearly the entire incident.io platform — incident management, alerting, on-call schedules, workflows, catalog, status pages, and admin/API operations.

## Getting Started

<Steps>
  <Step title="Generate an incident.io API Key">
    In your incident.io dashboard, go to **Settings → API keys** and generate a new key.
  </Step>
  <Step title="Add it to Shanone">
    Open **Integrations** in the Shanone dashboard, select incident.io, and paste in your API Key.
  </Step>
  <Step title="Retry your request">
    Once saved, `shanone_execute_tool` calls for `incidentio_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="incidentio_create_incident fails with a validation error about custom fields or roles">
    incident.io accounts often require certain custom fields or role assignments on creation — call `incidentio_list_custom_fields` and `incidentio_list_incident_roles` first to see what's mandatory for your workspace.
  </Accordion>
  <Accordion title="incidentio_list_schedule_entries returns unexpected gaps">
    Overrides (`incidentio_list_schedule_overrides`) take priority over the base rotation and aren't merged automatically into the entries view — check both endpoints if the on-call picture looks incomplete.
  </Accordion>
  <Accordion title="incidentio_resolve_alert doesn't close the linked incident">
    Alerts and incidents are related but distinct — resolving an alert doesn't automatically transition its incident; update the incident status explicitly with `incidentio_update_incident_status` if needed.
  </Accordion>
  <Accordion title="Admin tools like incidentio_create_api_key or incidentio_update_ip_allowlist return a permissions error">
    These endpoints require an API Key with admin-level scope — a key scoped only to incident management operations will be rejected for account/admin-level changes.
  </Accordion>
</AccordionGroup>
