# Neon

Shanone's Neon integration gives your agent 162 tools spanning project/branch lifecycle management, database administration, backups, Neon Auth, and organization-level billing and access control.

## Getting Started

<Steps>
  <Step title="Get a Neon API key">
    In the Neon console, go to **Account Settings > API Keys** and generate a new key.
  </Step>
  <Step title="Add the key in Shanone">
    Go to **Integrations > Neon** in the Shanone dashboard and paste the API key in.
  </Step>
  <Step title="Retry your request">
    Once saved, `shanone_execute_tool` calls for `neon_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="neon_create_branch succeeds but queries against it fail">
    A new branch needs a running compute endpoint — call `neon_create_endpoint` (or check if one was auto-created) and `neon_start_endpoint` before connecting.
  </Accordion>
  <Accordion title="neon_reveal_role_password returns an error">
    Passwords can only be revealed for roles created through Neon (not externally managed ones); use `neon_reset_role_password` to generate a new one if reveal isn't available.
  </Accordion>
  <Accordion title="Auth tools fail with an 'auth not enabled' error">
    Neon Auth must be explicitly turned on per project with `neon_enable_auth` before any `neon_auth_*`-adjacent config (domains, OAuth providers, plugins) can be managed.
  </Accordion>
  <Accordion title="Org-level tools return a permission error">
    Org member, billing, and VPC endpoint tools require an admin role in the Neon organization — check your role via `neon_get_org_member` for your own user ID.
  </Accordion>
</AccordionGroup>
