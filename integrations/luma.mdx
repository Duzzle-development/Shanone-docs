# Luma

Shanone's Luma integration gives your agent 36 tools for running events end-to-end: creating and updating events, managing guests and hosts, ticketing, coupons, and calendar memberships.

## Getting Started

<Steps>
  <Step title="Get a Luma API key">
    In your Luma calendar settings, generate an API key under the **API** section (requires a Luma Plus or higher plan).
  </Step>
  <Step title="Add the key in Shanone">
    Go to **Integrations > Luma** in the Shanone dashboard and paste the API key in.
  </Step>
  <Step title="Retry your request">
    Once saved, `shanone_execute_tool` calls for `luma_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="luma_create_ticket_type or coupon tools fail with a plan error">
    Ticketing and coupon features require a paid Luma plan on the calendar; free calendars can still manage guests and events but not paid ticketing.
  </Accordion>
  <Accordion title="luma_add_guests doesn't send invite emails">
    Adding a guest and inviting them are separate steps — call `luma_send_invites` afterward to actually email the added guests.
  </Accordion>
  <Accordion title="luma_import_people silently skips some rows">
    Duplicate emails and malformed rows are skipped rather than erroring; check the returned response for skipped/failed entries rather than assuming a full import.
  </Accordion>
</AccordionGroup>
