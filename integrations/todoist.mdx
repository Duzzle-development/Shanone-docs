# Todoist

Shanone's Todoist integration gives your agent 48 tools covering tasks, projects, sections, labels, comments, and reminders — plus collaboration and activity tracking — enough to run personal or team task management entirely through an agent.

## Getting Started

<Steps>
  <Step title="Generate an API token">
    In Todoist, go to **Settings → Integrations → Developer** and copy your API token.
  </Step>
  <Step title="Connect the API key in Shanone">
    Ask your agent to do something with Todoist (e.g. "add a task to buy groceries due tomorrow"), or add the API token proactively from **Integrations** in the Shanone dashboard.
  </Step>
  <Step title="Retry your request">
    Once connected, `shanone_execute_tool` calls for `todoist_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="todoist_get_tasks doesn't show a task I know exists">
    The default task list excludes completed tasks and can be scoped by project/filter — use `todoist_get_tasks_by_filter` with Todoist's filter syntax (e.g. `today`, `p1`, `#Work`) or `todoist_get_completed_tasks` for done items.
  </Accordion>
  <Accordion title="todoist_quick_add doesn't parse due dates or labels as expected">
    Quick-add relies on Todoist's natural-language parser for its text argument (e.g. `Submit report @work tomorrow p1`) — check `shanone_get_tool_schema` for `todoist_quick_add` and follow that syntax rather than passing structured fields.
  </Accordion>
  <Accordion title="todoist_delete_project or todoist_delete_label fails unexpectedly">
    Deletion is permanent and cascades (deleting a project deletes its tasks) — Todoist doesn't block this by default, so double-check the target ID before calling delete tools.
  </Accordion>
</AccordionGroup>
