# OpenSea

Shanone's OpenSea integration gives your agent 63 tools covering the full NFT marketplace surface — collection and NFT discovery, listings and offers, order fulfillment, portfolio/account stats, and on-chain token swaps.

## Getting Started

<Steps>
  <Step title="Create an OpenSea API key">
    Generate a key from the [OpenSea Developer Portal](https://opensea.io/account/settings/developer).
  </Step>
  <Step title="Add the key in Shanone">
    Go to **Integrations** in the Shanone dashboard, select OpenSea, and paste in your API key.
  </Step>
  <Step title="Retry your request">
    Once saved, `shanone_execute_tool` calls for `opensea_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="opensea_create_listing or opensea_create_offer fails with a signature error">
    These tools return an unsigned order payload that must be signed by the connected wallet before submission — check `shanone_get_tool_schema` to confirm whether signing happens client-side or via `opensea_create_listing_actions`.
  </Accordion>
  <Accordion title="opensea_fulfill_listing fails with an insufficient funds or allowance error">
    Confirm token allowances with `opensea_get_token_allowances` first; ERC-20 purchases (not ETH) usually require an approval transaction before the marketplace contract can spend the buyer's tokens.
  </Accordion>
  <Accordion title="Stats or floor price look stale">
    `opensea_get_collection_stats` and related aggregates can lag real-time trades by a short window; use `opensea_refresh_nft_metadata` for individual NFTs if metadata specifically looks outdated.
  </Accordion>
</AccordionGroup>
