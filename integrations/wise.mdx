# Wise

Shanone's Wise integration gives your agent 57 tools for cross-border money movement — quotes, transfers, recipients, multi-currency balances, and the profile/webhook tools needed to run it programmatically.

## Getting Started

<Steps>
  <Step title="Create a Wise Personal Access Token">
    Generate a token from [wise.com/settings/api-tokens](https://wise.com/settings/api-tokens) under **Settings → API tokens → Personal access tokens**.
  </Step>
  <Step title="Connect via API key">
    In the Shanone dashboard, go to **Integrations → Wise** and paste the token.
  </Step>
  <Step title="Retry your request">
    Once connected, `shanone_execute_tool` calls for `wise_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="wise_create_transfer fails after a valid quote">
    Transfers require a funded balance or valid payment method — call `wise_fund_transfer` (or ensure sufficient balance via `wise_list_balances`) right after creation, since an unfunded transfer stays in an incomplete state.
  </Accordion>
  <Accordion title="wise_create_recipient rejects the payload">
    Recipient requirements vary by currency and country. Call `wise_get_recipient_requirements` for the target currency first to see which fields (IBAN, sort code, routing number, etc.) are mandatory before submitting.
  </Accordion>
  <Accordion title="wise_check_recipient_quote_compatibility returns incompatible">
    A quote is created for a specific source/target currency pair; if the recipient's currency doesn't match the quote's target currency, create a new quote for that pair rather than reusing an old one.
  </Accordion>
</AccordionGroup>
