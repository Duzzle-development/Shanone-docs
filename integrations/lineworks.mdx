# LINE WORKS

Shanone's LINE WORKS integration gives your agent 350 tools — the largest in Shanone's catalog — covering everyday messaging, mail, calendar, and drive alongside deep directory administration (users, groups, org units, custom fields) and bot management.

## Getting Started

<Steps>
  <Step title="Register a LINE WORKS Developer app">
    In the [LINE WORKS Developer Console](https://developers.worksmobile.com), create an app and generate a Client ID, Client Secret, and a Service Account with a private key for JWT-based authentication.
  </Step>
  <Step title="Add all four credentials in Shanone">
    Go to **Integrations > LINE WORKS** in the Shanone dashboard and enter the Client ID, Client Secret, Service Account, and Private Key — all four are required to mint access tokens.
  </Step>
  <Step title="Retry your request">
    Once saved, `shanone_execute_tool` calls for `lineworks_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="All lineworks_* tool calls fail with an authentication error">
    LINE WORKS uses JWT-based service account auth, not a simple bearer token — Client ID, Client Secret, Service Account, and Private Key must all be correctly set; a single missing or malformed field prevents any token from being issued.
  </Accordion>
  <Accordion title="Directory admin tools (users, groups, levels) return a permission error">
    These tools require the connected app to have Directory Management API scopes granted in the Developer Console for that app — messaging-only scopes aren't sufficient.
  </Accordion>
  <Accordion title="lineworks_delete_member doesn't seem to fully remove the user">
    Standard delete is often a soft-delete/deactivation; use `lineworks_force_delete_member` if you need to permanently and immediately remove a member record.
  </Accordion>
  <Accordion title="Bot-related tools fail even though the bot exists">
    Bot messaging tools operate under a specific bot's credentials registered via `lineworks_create_bot` — confirm the bot ID you're targeting is authorized for the domain with `lineworks_list_bot_domains`.
  </Accordion>
</AccordionGroup>
