# Confluence

Shanone's Confluence integration gives your agent 46 tools for Atlassian Confluence: pages, blog posts, comments, labels, attachments, spaces, tasks, and search.

## Getting Started

<Steps>
  <Step title="Generate an Atlassian API Token">
    Go to [Atlassian API tokens](https://id.atlassian.com/manage-profile/security/api-tokens) and create a new token for your account.
  </Step>
  <Step title="Add credentials to Shanone">
    Open **Integrations** in the Shanone dashboard, select Confluence, and enter your Atlassian account email along with the API Token.
  </Step>
  <Step title="Retry your request">
    Once saved, `shanone_execute_tool` calls for `confluence_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Tools fail with a 401 despite a valid-looking token">
    Confluence Cloud requires the account **email** and API Token together (Basic Auth), not the token alone — double-check both fields were saved in the Integrations page.
  </Accordion>
  <Accordion title="confluence_create_page fails with a body format error">
    Confluence's page body uses Atlassian Document Format (ADF) or storage-format XHTML depending on the API version — check `shanone_get_tool_schema` for `confluence_create_page` to confirm which format is expected before sending rich content.
  </Accordion>
  <Accordion title="confluence_search returns fewer results than expected">
    `confluence_search` uses CQL (Confluence Query Language) under the hood; a plain keyword works, but for precise filtering (by space, label, or type) construct a proper CQL expression rather than free text.
  </Accordion>
</AccordionGroup>
