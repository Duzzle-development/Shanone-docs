# Composio

Shanone's Composio integration gives your agent 60 tools for Composio itself: a meta-layer that discovers and executes tools across 1000+ external services (GitHub, Gmail, Slack, and more) through managed OAuth/API key connections.

## Getting Started

<Steps>
  <Step title="Get a Composio API Key">
    Sign in to [app.composio.dev](https://app.composio.dev) and copy your API Key from **Settings**.
  </Step>
  <Step title="Add it to Shanone">
    Open **Integrations** in the Shanone dashboard, select Composio, and paste in the API Key.
  </Step>
  <Step title="Retry your request">
    Once saved, `shanone_execute_tool` calls for `composio_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="composio_execute_tool fails with a missing connected account error">
    The target toolkit needs its own connected account first — use `composio_create_auth_link` to get an authorization URL, have the end user complete it, then poll `composio_wait_for_connection` before executing.
  </Accordion>
  <Accordion title="composio_search_tools returns too many irrelevant results">
    Narrow the query with a specific `toolkit_slug` filter, or use `composio_find_tool_for_task` instead, which is tuned to return a single best match for a natural-language task description.
  </Accordion>
  <Accordion title="Tool Router session tools disappear after some time">
    Router sessions (`composio_create_router_session`) are time-scoped; check `composio_get_router_session` for its expiry and call `composio_update_router_session` or create a new session if it has lapsed.
  </Accordion>
</AccordionGroup>
