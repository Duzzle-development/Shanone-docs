# GitLab

Shanone's GitLab integration gives your agent 60 tools covering the full development workflow — issues, merge requests, branches/commits, CI/CD pipelines and jobs, and repository file operations.

## Getting Started

<Steps>
  <Step title="Connect via OAuth">
    Ask your agent to do something with GitLab (e.g. "list open merge requests assigned to me"), or connect proactively from **Integrations** in the Shanone dashboard.
  </Step>
  <Step title="Authorize the GitLab account">
    Approve GitLab's OAuth consent screen for the account/group you want Shanone to act on.
  </Step>
  <Step title="Retry your request">
    Once connected, `shanone_execute_tool` calls for `gitlab_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="gitlab_get_job_log returns truncated or empty output">
    GitLab job logs can be very large and are streamed — for long-running jobs, call `gitlab_get_job_log` again after the job finishes to get the complete trace rather than a partial one mid-run.
  </Accordion>
  <Accordion title="gitlab_create_file or gitlab_update_file fails with a branch conflict">
    These operations commit directly to a branch — pass the correct `branch` parameter and make sure no one else has pushed conflicting changes since you last read the file with `gitlab_get_file`.
  </Accordion>
  <Accordion title="Pipeline or job tools return a 403/permission error">
    Retrying, canceling, or playing pipelines/jobs requires at least Developer-level access on the project for the connected GitLab account — check `gitlab_list_project_members` if unsure.
  </Accordion>
</AccordionGroup>
