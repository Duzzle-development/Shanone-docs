# HeyGen

Shanone's HeyGen integration gives your agent 69 tools covering nearly all of HeyGen's video generation platform — avatars, voices, lipsync, video translation, templates, batch/bulk operations, and webhooks.

## Getting Started

<Steps>
  <Step title="Get your HeyGen API Key">
    Generate a key from **Settings → API** in your HeyGen account.
  </Step>
  <Step title="Add it to Shanone">
    Open **Integrations** in the Shanone dashboard, select HeyGen, and paste in your API Key.
  </Step>
  <Step title="Retry your request">
    Once saved, `shanone_execute_tool` calls for `heygen_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="heygen_create_video succeeds but the video stays in a processing state">
    HeyGen renders asynchronously — poll `heygen_get_video` (or use `heygen_bulk_video_statuses` for batches) until `status` reports `completed` or `failed` rather than assuming a queued response means the video is ready.
  </Accordion>
  <Accordion title="heygen_clone_voice or heygen_create_avatar fails with a consent error">
    Voice cloning and photo avatars require explicit consent recording via `heygen_create_avatar_consent` before the underlying asset can be used — this is a legal/compliance requirement on HeyGen's side, not a Shanone limitation.
  </Accordion>
  <Accordion title="Webhook events aren't arriving for a video that finished rendering">
    Confirm the endpoint URL registered with `heygen_create_webhook_endpoint` is publicly reachable over HTTPS, and check `heygen_list_webhook_event_types` to make sure you subscribed to the right event type for that action.
  </Accordion>
</AccordionGroup>
