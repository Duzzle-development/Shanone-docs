# Jira

Shanone's Jira integration gives your agent 47 tools for Jira Cloud project management — issues, projects, boards, sprints, worklogs, dashboards, filters, and more, across multi-site Atlassian accounts.

## Getting Started

<Steps>
  <Step title="Connect via OAuth">
    Ask your agent to do something with Jira (e.g. "create a bug ticket for the login issue"), or connect proactively from **Integrations** in the Shanone dashboard.
  </Step>
  <Step title="Authorize the Atlassian account">
    Approve Atlassian's OAuth consent screen and select the Jira site (cloud instance) Shanone should access.
  </Step>
  <Step title="Retry your request">
    Once connected, `shanone_execute_tool` calls for `jira_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="jira_create_issue fails with a required field error">
    Different Jira projects have different required fields (e.g. custom fields, components) — call `jira_get_project` and `jira_get_issue_types` first to see what's mandatory before creating, especially for issue types beyond the default Task/Bug/Story.
  </Accordion>
  <Accordion title="jira_transition_issue fails saying the transition isn't valid">
    Available transitions depend on the issue's current status and the project's workflow — call `jira_get_transitions` first to get the exact transition IDs available from the issue's current state, rather than assuming a status name maps directly to a transition.
  </Accordion>
  <Accordion title="Tools return a 401/403 error even though I connected successfully">
    Jira Cloud accounts can have multiple sites (cloud_id); if you have access to more than one Jira site, confirm the OAuth connection is scoped to the site containing the project you're trying to reach — reconnect via Integrations to pick a different site if needed.
  </Accordion>
</AccordionGroup>
