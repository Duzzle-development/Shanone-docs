# Box

Shanone's Box integration gives your agent 100 tools covering Box's full content management surface — files/folders, sharing and collaboration, metadata templates, tasks, e-signatures, and Box AI's ask/extract capabilities.

## Getting Started

<Steps>
  <Step title="Connect via OAuth">
    Ask your agent to do something with Box (e.g. "find the latest contract in my Legal folder"), or connect proactively from **Integrations** in the Shanone dashboard.
  </Step>
  <Step title="Authorize your Box account">
    Approve Box's OAuth consent screen for the account/enterprise you want Shanone to access.
  </Step>
  <Step title="Retry your request">
    Once connected, `shanone_execute_tool` calls for `box_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="box_ai_ask or box_ai_extract returns an unsupported file type error">
    Box AI only supports a subset of file types (mainly documents, PDFs, and some image formats) — convert the file or check the file type against Box AI's supported format list.
  </Accordion>
  <Accordion title="box_create_collaboration fails with an insufficient permission error">
    Only users with an appropriate role on the target folder can invite new collaborators. Check the requesting account's role with `box_get_collaboration` before retrying.
  </Accordion>
  <Accordion title="box_upload_file fails for a large file">
    Box requires chunked uploads above roughly 20MB. Use `box_chunked_upload` (with `box_preflight_check` first) instead of `box_upload_file` for large files.
  </Accordion>
</AccordionGroup>
