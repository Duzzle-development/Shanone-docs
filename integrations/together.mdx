# Together AI

Shanone's Together AI integration gives your agent 127 tools spanning serverless inference (chat/completions/embeddings/rerank), fine-tuning, batch and evaluation jobs, GPU cluster management, and Dedicated Model Inference (DMI) — a broad surface for teams running their own models on Together's infrastructure.

## Getting Started

<Steps>
  <Step title="Generate an API key">
    In the Together AI dashboard, go to **Settings → API Keys** and create a key.
  </Step>
  <Step title="Connect the API key in Shanone">
    Ask your agent to do something with Together AI (e.g. "list the models available for fine-tuning"), or add the API key proactively from **Integrations** in the Shanone dashboard.
  </Step>
  <Step title="Retry your request">
    Once connected, `shanone_execute_tool` calls for `together_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="together_create_fine_tuning_job fails on validation">
    Use `together_estimate_fine_tuning_price` first — it validates the training file and base model compatibility before you commit to a paid job.
  </Accordion>
  <Accordion title="A DMI deployment stays in a pending state">
    Dedicated Model Inference deployments provision GPU capacity and can take several minutes — poll `together_dmi_get_deployment` (or `together_dci_get_deployment` for container-based deployments) rather than assuming failure.
  </Accordion>
  <Accordion title="together_execute_code doesn't retain state between calls">
    Code interpreter sessions are explicit — use `together_list_code_sessions` to find or reuse an existing session ID; a fresh call without one starts a brand-new session.
  </Accordion>
  <Accordion title="GPU cluster operations fail with a quota or capacity error">
    GPU clusters are a scarce, billed resource — check `together_list_cluster_regions` for availability and confirm your account's quota before retrying `together_create_gpu_cluster`.
  </Accordion>
</AccordionGroup>
