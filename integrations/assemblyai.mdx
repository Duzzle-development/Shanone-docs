# AssemblyAI

Shanone's AssemblyAI integration gives your agent 17 tools for speech-to-text — asynchronous and synchronous transcription, speaker identification and translation, and an LLM gateway for summarizing or asking questions about a transcript.

## Getting Started

<Steps>
  <Step title="Get an AssemblyAI API key">
    Sign in to your [AssemblyAI account](https://www.assemblyai.com/app/account) and copy your API key.
  </Step>
  <Step title="Connect in Shanone">
    Ask your agent to transcribe an audio/video file, or add the API key proactively from **Integrations** in the Shanone dashboard.
  </Step>
  <Step title="Retry your request">
    Once the key is stored, `shanone_execute_tool` calls for `assemblyai_*` tools will succeed.
  </Step>
</Steps>

## Available Tools

Shanone provides **17 tools** for AssemblyAI, organized into these categories:

<AccordionGroup>
  <Accordion title="Transcription">
    `assemblyai_transcribe`, `assemblyai_get_transcript`, `assemblyai_list_transcripts`, `assemblyai_delete_transcript`, `assemblyai_upload_file`
  </Accordion>
  <Accordion title="Synchronous transcription">
    `assemblyai_sync_transcribe` — transcribe short audio and get the result in a single blocking call, instead of polling
  </Accordion>
  <Accordion title="Speech understanding">
    `assemblyai_translate_transcript`, `assemblyai_identify_speakers`, `assemblyai_apply_custom_formatting`
  </Accordion>
  <Accordion title="LLM gateway">
    `assemblyai_llm_chat`, `assemblyai_llm_summary`, `assemblyai_llm_qa`, `assemblyai_llm_action_items`
  </Accordion>
  <Accordion title="Exports & search">
    `assemblyai_export_subtitles`, `assemblyai_get_sentences`, `assemblyai_get_paragraphs`, `assemblyai_search_words`
  </Accordion>
</AccordionGroup>

## Troubleshooting

<AccordionGroup>
  <Accordion title="assemblyai_transcribe returns a transcript stuck in 'processing'">
    Async transcription is queue-based; poll `assemblyai_get_transcript` with the returned ID until `status` becomes `completed`, rather than expecting an immediate result.
  </Accordion>
  <Accordion title="assemblyai_sync_transcribe fails or times out on a long file">
    Synchronous transcription is intended for short audio only. Use `assemblyai_transcribe` (async) with polling for longer recordings.
  </Accordion>
  <Accordion title="assemblyai_llm_qa or assemblyai_llm_summary returns an error about a missing transcript">
    The transcript must have finished processing (`status: completed`) before LLM gateway tools can operate on it — check with `assemblyai_get_transcript` first.
  </Accordion>
</AccordionGroup>
