# Asana

Shanone's Asana integration gives your agent 115 tools — one of the deepest integrations in the catalog, covering not just tasks and projects but portfolios, goals, custom fields, dependencies, time tracking, and webhooks.

## Getting Started

<Steps>
  <Step title="Connect via OAuth">
    Ask your agent to do something with Asana (e.g. "create a task in my Q3 Roadmap project"), or connect proactively from **Integrations** in the Shanone dashboard.
  </Step>
  <Step title="Authorize the workspace">
    Approve Asana's OAuth consent screen for the workspace(s) you want Shanone to access.
  </Step>
  <Step title="Retry your request">
    Once connected, `shanone_execute_tool` calls for `asana_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="asana_create_task fails with an invalid custom field value">
    Custom field option IDs (for enum/dropdown fields) must match exactly what `asana_get_custom_field` returns — free-text values won't work for enum-type fields.
  </Accordion>
  <Accordion title="asana_search_tasks returns fewer results than expected">
    Asana's search API only searches within a single workspace at a time and has its own field-limiting rules; confirm the `workspace` parameter matches the project's actual workspace.
  </Accordion>
  <Accordion title="asana_create_webhook succeeds but no events arrive">
    Asana requires the webhook target to respond to a handshake request immediately after creation — if your endpoint doesn't complete the handshake, Asana silently disables the webhook.
  </Accordion>
</AccordionGroup>
