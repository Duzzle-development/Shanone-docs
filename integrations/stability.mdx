# Stability AI

Shanone's Stability AI integration gives your agent 28 tools for image generation, editing (inpainting, outpainting, background removal), control-guided generation, upscaling, 3D asset generation, and text-to-audio — covering most of Stability's generative media API.

## Getting Started

<Steps>
  <Step title="Generate an API key">
    In the Stability AI Platform, go to **Account → API Keys** and create a key.
  </Step>
  <Step title="Connect the API key in Shanone">
    Ask your agent to do something with Stability (e.g. "generate an image of a lighthouse at sunset"), or add the API key proactively from **Integrations** in the Shanone dashboard.
  </Step>
  <Step title="Retry your request">
    Once connected, `shanone_execute_tool` calls for `stability_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="A generation call returns a 402 or balance error">
    Stability AI bills per generation by credits. Check `stability_get_balance` before running large batches to avoid mid-batch failures.
  </Accordion>
  <Accordion title="stability_generate_3d or an audio tool doesn't return the asset immediately">
    3D and some audio generations run asynchronously and return a job/generation ID — poll `stability_fetch_image_result` or `stability_fetch_audio_result` with that ID until the asset is ready.
  </Accordion>
  <Accordion title="stability_inpaint or stability_erase produces unexpected results">
    These tools rely on a mask image aligned to the source image's dimensions — check `shanone_get_tool_schema` for `stability_inpaint` to confirm the mask format (grayscale, matching resolution) expected.
  </Accordion>
</AccordionGroup>
