# Perplexity

Shanone's Perplexity integration gives your agent 1 tool for AI-powered, citation-backed web search — a lightweight way to ground answers in real-time information without building your own search pipeline.

## Getting Started

<Steps>
  <Step title="Create a Perplexity API key">
    Generate a key from the [Perplexity API settings page](https://www.perplexity.ai/settings/api).
  </Step>
  <Step title="Add the key in Shanone">
    Go to **Integrations** in the Shanone dashboard, select Perplexity, and paste in the key (`pplx-...`).
  </Step>
  <Step title="Retry your request">
    Once saved, `shanone_execute_tool` calls for `perplexity_*` tools will succeed.
  </Step>
</Steps>

## Available Tools

Shanone provides **1 tool** for Perplexity, organized into this category:

<AccordionGroup>
  <Accordion title="Search">
    `perplexity_search` — ask a natural-language question and get an AI-generated answer with cited sources, using a selectable model tier (`small`/`large`/`huge`)
  </Accordion>
</AccordionGroup>

## Troubleshooting

<AccordionGroup>
  <Accordion title="perplexity_search returns an authentication error">
    Confirm the key saved in **Integrations** starts with `pplx-` — keys from other Perplexity products (e.g. Comet) won't work with the Sonar API.
  </Accordion>
  <Accordion title="Answers feel shallow for a complex question">
    Try the `huge` model tier instead of the default `small` — it trades speed for better reasoning on complex or multi-part questions.
  </Accordion>
  <Accordion title="perplexity_search is rate limited">
    Perplexity API plans have per-minute rate limits tied to the account behind the key; wait and retry, or check usage on the Perplexity dashboard.
  </Accordion>
</AccordionGroup>
