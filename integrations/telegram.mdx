# Telegram

Shanone's Telegram integration gives your agent 38 tools for sending and managing messages, administering chats/groups, moderating members, and configuring the bot itself — everything you need to run a Telegram bot's day-to-day behavior through an agent instead of custom bot code.

## Getting Started

<Steps>
  <Step title="Create a bot with BotFather">
    In Telegram, message [@BotFather](https://t.me/BotFather), run `/newbot`, and follow the prompts to get a Bot Token.
  </Step>
  <Step title="Connect the Bot Token in Shanone">
    Ask your agent to do something with Telegram (e.g. "send a message to this chat"), or add the Bot Token proactively from **Integrations** in the Shanone dashboard.
  </Step>
  <Step title="Retry your request">
    Once connected, `shanone_execute_tool` calls for `telegram_*` tools will succeed. Your bot must already be a member of any chat/group it acts on.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="A chat-targeted tool fails even though the bot token is valid">
    The bot must be added as a member (and often an admin, for moderation actions) of the target chat/group/channel — a valid token alone doesn't grant access to arbitrary chats.
  </Accordion>
  <Accordion title="telegram_ban_chat_member, telegram_restrict_chat_member, or telegram_promote_chat_member fails">
    These require the bot to have admin rights with the specific permission in that chat (e.g. "Ban users" or "Add new admins") — check the bot's admin permissions in the chat's settings.
  </Accordion>
  <Accordion title="telegram_get_updates returns nothing">
    If a webhook is already set via `telegram_set_webhook`, Telegram stops delivering updates through the polling-based `telegram_get_updates` — call `telegram_delete_webhook` first if you want to switch back to polling.
  </Accordion>
</AccordionGroup>
