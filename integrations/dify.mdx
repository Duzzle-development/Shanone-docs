# Dify

Shanone's Dify integration gives your agent 65 tools for the Dify AI application platform: chat/completion messages, workflows, knowledge base management, document processing, chunks, tags, metadata, and annotations.

## Getting Started

<Steps>
  <Step title="Get a Dify App API Key">
    In your Dify app, go to **API Access** and copy the app's API Key (starts with `app-`).
  </Step>
  <Step title="Add it to Shanone">
    Open **Integrations** in the Shanone dashboard, select Dify, and paste in the API Key.
  </Step>
  <Step title="Retry your request">
    Once saved, `shanone_execute_tool` calls for `dify_*` tools will succeed.
  </Step>
</Steps>

<Note>
Dify API Keys are scoped to a single app (or knowledge base). If you need to work across multiple Dify apps, you may need separate connections or check how your Shanone workspace manages multiple Dify keys.
</Note>

## Troubleshooting

<AccordionGroup>
  <Accordion title="dify_chat_message returns an app-type mismatch error">
    Chat apps and Completion apps use different endpoints — use `dify_completion_message` instead of `dify_chat_message` if your Dify app is configured as a Text Generator / Completion app rather than a Chatbot.
  </Accordion>
  <Accordion title="Uploaded document stays stuck at 'indexing'">
    Poll `dify_get_document_indexing_status` — large files or documents with heavy chunking rules can take a while; if it never finishes, check the file format is supported by the knowledge base's configured indexing method.
  </Accordion>
  <Accordion title="dify_run_workflow times out on a long-running workflow">
    For workflows with slow steps, don't wait on the initial call alone — poll `dify_get_workflow_run_detail` with the returned `workflow_run_id` until the status is terminal.
  </Accordion>
</AccordionGroup>
