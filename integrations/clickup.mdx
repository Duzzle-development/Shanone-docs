# ClickUp

Shanone's ClickUp integration gives your agent 166 tools covering nearly every corner of ClickUp: tasks, lists, folders, spaces, docs, goals, time tracking, chat, guests, and workspace administration.

## Getting Started

<Steps>
  <Step title="Generate a Personal API Token">
    In ClickUp, go to your **Settings → Apps** page and copy your Personal API Token (starts with `pk_`).
  </Step>
  <Step title="Add it to Shanone">
    Open **Integrations** in the Shanone dashboard, select ClickUp, and paste in the token.
  </Step>
  <Step title="Retry your request">
    Once saved, `shanone_execute_tool` calls for `clickup_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="clickup_create_task fails with a custom field error">
    Custom field values must be set separately via `clickup_set_custom_field_value` after task creation — `clickup_create_task` doesn't accept arbitrary custom fields directly unless the schema explicitly supports them.
  </Accordion>
  <Accordion title="Chat tools return a 403">
    ClickUp Chat is a newer product surface and may not be enabled on all workspace plans; confirm Chat is active in the ClickUp workspace before calling `clickup_*chat*` tools.
  </Accordion>
  <Accordion title="Can't find the right list_id/folder_id/space_id">
    Walk the hierarchy top-down: `clickup_list_workspaces` → `clickup_list_spaces` → `clickup_list_folders` → `clickup_list_lists`. IDs aren't guessable and must come from these listing calls.
  </Accordion>
</AccordionGroup>
