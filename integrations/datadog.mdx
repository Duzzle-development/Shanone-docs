# Datadog

Shanone's Datadog integration gives your agent 39 tools for observability: metrics, monitors, dashboards, logs, traces, hosts, SLOs, downtimes, and synthetics.

## Getting Started

<Steps>
  <Step title="Generate an API Key and Application Key">
    In Datadog, go to **Organization Settings → API Keys** to create an API Key, and **Organization Settings → Application Keys** for an Application Key. Both are required together.
  </Step>
  <Step title="Add credentials to Shanone">
    Open **Integrations** in the Shanone dashboard, select Datadog, and enter both the API Key and Application Key.
  </Step>
  <Step title="Retry your request">
    Once saved, `shanone_execute_tool` calls for `datadog_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Tools fail even though one of API Key or Application Key is set">
    Datadog requires **both** an API Key and an Application Key together — a monitoring-only API Key alone isn't sufficient for most read/write operations exposed here. Check both fields are saved in Integrations.
  </Accordion>
  <Accordion title="datadog_query_metrics returns no data points">
    Confirm the metric name and tags exist by checking `datadog_list_metrics` first, and make sure the time range (`from`/`to`) actually overlaps with when the metric was reported.
  </Accordion>
  <Accordion title="datadog_search_logs returns fewer results than expected">
    Log retention and indexing are governed by the target log index's retention policy — check `datadog_list_log_indexes` to confirm the index being searched actually retains logs for the requested time range.
  </Accordion>
</AccordionGroup>
