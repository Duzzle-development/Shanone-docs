# X

Shanone's X integration gives your agent 67 tools covering posting and engagement, timelines and search, lists, direct messages, and Spaces.

## Getting Started

<Steps>
  <Step title="Connect via OAuth">
    Ask your agent to do something with X (e.g. "post an update about our launch"), or connect proactively from **Integrations** in the Shanone dashboard.
  </Step>
  <Step title="Authorize the X account">
    Approve X's OAuth consent screen for the account you want Shanone to act on.
  </Step>
  <Step title="Retry your request">
    Once connected, `shanone_execute_tool` calls for `x_*` tools will succeed.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="x_upload_media fails for a large video file">
    Large media requires the chunked upload flow — call `x_upload_media_init`, then one or more `x_upload_media_append` calls, then `x_upload_media_finalize`, and poll `x_get_media_upload_status` before attaching the media ID to a post.
  </Accordion>
  <Accordion title="x_create_post with media attached is rejected">
    The media must finish processing (see `x_get_media_upload_status`) before its media ID can be referenced in `x_create_post` — attaching an in-progress upload will fail.
  </Accordion>
  <Accordion title="x_search_posts returns fewer results than expected">
    X's search API has retention/rate limits on the standard tier; very old posts or high-volume queries may return partial results. Narrow the query or check `x_get_post_counts` to sanity-check expected volume.
  </Accordion>
  <Accordion title="OAuth connection stops working after a while">
    X's OAuth 2.0 access tokens expire; if calls start failing with an auth error, reconnect from **Integrations** to refresh the token rather than assuming a persistent connection.
  </Accordion>
</AccordionGroup>
