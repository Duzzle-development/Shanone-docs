# Wise

Shanoneのwise連携は、国際的な資金移動 — 見積もり、送金、受取人、多通貨残高、そしてこれらをプログラム的に運用するためのプロフィール/Webhookツールまで含む57個のツールをエージェントに提供します。

## はじめに

<Steps>
  <Step title="WiseのPersonal Access Tokenを作成する">
    [wise.com/settings/api-tokens](https://wise.com/settings/api-tokens)の**設定 → API tokens → Personal access tokens**からトークンを発行します。
  </Step>
  <Step title="APIキーで接続する">
    Shanoneダッシュボードの**連携 → Wise**でトークンを貼り付けます。
  </Step>
  <Step title="リクエストを再実行する">
    接続が完了すると、`wise_*`ツールに対する`shanone_execute_tool`呼び出しが成功するようになります。
  </Step>
</Steps>

## トラブルシューティング

<AccordionGroup>
  <Accordion title="有効な見積もりの後もwise_create_transferが失敗する">
    送金には資金投入済みの残高か有効な決済手段が必要です — 作成直後に`wise_fund_transfer`を呼ぶか(または`wise_list_balances`で十分な残高を確認)してください。資金未投入の送金は未完了状態のままになります。
  </Accordion>
  <Accordion title="wise_create_recipientがペイロードを拒否する">
    受取人の必須項目は通貨・国によって異なります。送信前に対象通貨で`wise_get_recipient_requirements`を呼び出し、必須フィールド(IBAN、ソートコード、ルーティング番号など)を確認してください。
  </Accordion>
  <Accordion title="wise_check_recipient_quote_compatibilityがincompatibleを返す">
    見積もりは特定の送金元/送金先通貨ペアに対して作成されます。受取人の通貨が見積もりの送金先通貨と一致しない場合は、古い見積もりを再利用せずそのペア用に新しい見積もりを作成してください。
  </Accordion>
</AccordionGroup>
