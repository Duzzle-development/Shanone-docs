# CircleCI

ShanoneのCircleCI連携は、CI/CD関連の111個のツールをエージェントに提供します。パイプライン、ワークフロー、ジョブ、プロジェクト、コンテキスト、ポリシー、OIDC、パイプラインインサイトが対象です。

## はじめに

<Steps>
  <Step title="Personal API Tokenを発行する">
    CircleCIの**User Settings → Personal API Tokens**で新しいトークンを作成します。
  </Step>
  <Step title="Shanoneに登録する">
    Shanoneダッシュボードの**連携**を開き、CircleCIを選択してPersonal API Tokenを貼り付けます。
  </Step>
  <Step title="リクエストを再実行する">
    保存が完了すると、`circleci_*`ツールに対する`shanone_execute_tool`呼び出しが成功するようになります。
  </Step>
</Steps>

## トラブルシューティング

<AccordionGroup>
  <Accordion title="circleci_trigger_pipelineが404を返す">
    `project_slug`は`vcs-slug/org-name/repo-name`の形式(例: `gh/my-org/my-repo`)である必要があります。トリガーする前に`circleci_get_project`で正確なslugを確認してください。
  </Accordion>
  <Accordion title="コンテキストや環境変数系のツールが権限エラーを返す">
    コンテキストとその環境変数を管理するには、Personal API Tokenのアカウントが組織の管理者権限を持っている必要があります。管理者権限のないユーザーのトークンではパイプラインの読み取りはできますが、シークレットの書き込みはできません。
  </Accordion>
  <Accordion title="作成したばかりのプロジェクトでインサイト系のツールがデータを返さない">
    CircleCI Insightsはデータを遅延して集計し、実際に実行されたパイプラインのみを対象とします。新規または実行頻度の低いプロジェクトにはまだサマリーデータがありません。
  </Accordion>
</AccordionGroup>
