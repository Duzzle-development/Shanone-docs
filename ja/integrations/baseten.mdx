# Baseten

ShanoneのBaseten連携では、**129個のツール**をエージェントに提供します — カタログ内最大のML基盤連携で、モデルのデプロイ・推論、複数ステップのチェーン、非同期キュー、トレーニングジョブ、モデルゲートウェイのルーティング、ワークスペース/請求管理までカバーしています。

## はじめに

<Steps>
  <Step title="Baseten APIキーを発行する">
    Basetenダッシュボードの**Settings > API Keys**で新しいキーを発行します。
  </Step>
  <Step title="Shanoneで接続する">
    エージェントにBasetenで何か作業をしてもらう(例:「デプロイ済みモデルで推論を実行して」)か、Shanoneダッシュボードの**インテグレーション**からAPIキーを事前に登録します。
  </Step>
  <Step title="リクエストを再試行する">
    キーが保存されると、`baseten_*`ツールに対する`shanone_execute_tool`の呼び出しが成功するようになります。
  </Step>
</Steps>

## トラブルシューティング

<AccordionGroup>
  <Accordion title="baseten_predict_modelがコールドスタートの遅延やタイムアウトを返す">
    ゼロスケールされたデプロイメントは、応答する前に起動が必要です。先に`baseten_wake_model`を呼ぶか、`baseten_predict_model`にバックオフ付きのリトライを追加してください。
  </Accordion>
  <Accordion title="baseten_predict_model_asyncがいつまでも完了しない">
    非同期推論はキュー経由で処理されます。同期的な結果を期待するのではなく、返されたリクエストIDで`baseten_get_async_request_status`をポーリングしてください。
  </Accordion>
  <Accordion title="リージョン指定版のツール(baseten_predict_model_regionalなど)がデフォルトのツールと異なる動きをする">
    リージョン指定版のツールは、Basetenのデフォルトルーティングではなく特定のデプロイメントリージョンを対象とします — レイテンシやコンプライアンス上の理由で推論を特定リージョンに固定したい場合にのみ使用してください。
  </Accordion>
</AccordionGroup>
