# ClickUp

ShanoneのClickUp連携は、ClickUpのほぼすべての領域を扱う166個のツールをエージェントに提供します。タスク、リスト、フォルダ、スペース、ドキュメント、ゴール、時間管理、チャット、ゲスト、ワークスペース管理が対象です。

## はじめに

<Steps>
  <Step title="Personal API Tokenを発行する">
    ClickUpの**Settings → Apps**ページでPersonal API Token(`pk_`で始まるトークン)をコピーします。
  </Step>
  <Step title="Shanoneに登録する">
    Shanoneダッシュボードの**連携**を開き、ClickUpを選択してトークンを貼り付けます。
  </Step>
  <Step title="リクエストを再実行する">
    保存が完了すると、`clickup_*`ツールに対する`shanone_execute_tool`呼び出しが成功するようになります。
  </Step>
</Steps>

## トラブルシューティング

<AccordionGroup>
  <Accordion title="clickup_create_taskがカスタムフィールドのエラーで失敗する">
    カスタムフィールドの値は、タスク作成後に`clickup_set_custom_field_value`で別途設定する必要があります。スキーマが明示的にサポートしていない限り、`clickup_create_task`は任意のカスタムフィールドを直接受け付けません。
  </Accordion>
  <Accordion title="チャット系のツールが403を返す">
    ClickUp Chatは比較的新しい機能であり、すべてのワークスペースプランで有効になっているわけではありません。`clickup_*chat*`系のツールを呼び出す前に、ClickUpワークスペースでChatが有効化されているか確認してください。
  </Accordion>
  <Accordion title="正しいlist_id/folder_id/space_idが分からない">
    階層を上から順にたどってください: `clickup_list_workspaces` → `clickup_list_spaces` → `clickup_list_folders` → `clickup_list_lists`。IDは推測できないため、必ずこれらの一覧取得の呼び出しから取得してください。
  </Accordion>
</AccordionGroup>
