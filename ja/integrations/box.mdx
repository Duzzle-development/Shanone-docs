# Box

ShanoneのBox連携では、Boxのコンテンツ管理機能全体をカバーする**100個のツール**をエージェントに提供します — ファイル/フォルダ、共有・コラボレーション、メタデータテンプレート、タスク、電子署名、そしてBox AIのask/extract機能まで扱えます。

## はじめに

<Steps>
  <Step title="OAuthで接続する">
    エージェントにBoxで何か作業をしてもらう(例:「Legalフォルダの最新の契約書を探して」)か、Shanoneダッシュボードの**インテグレーション**から事前に接続します。
  </Step>
  <Step title="Boxアカウントを承認する">
    Shanoneにアクセスさせたいアカウント/エンタープライズについて、BoxのOAuth承認画面で承認します。
  </Step>
  <Step title="リクエストを再試行する">
    接続が完了すると、`box_*`ツールに対する`shanone_execute_tool`の呼び出しが成功するようになります。
  </Step>
</Steps>

## トラブルシューティング

<AccordionGroup>
  <Accordion title="box_ai_askやbox_ai_extractが未対応のファイル形式エラーを返す">
    Box AIが対応しているのは一部のファイル形式(主にドキュメント、PDF、一部の画像形式)のみです — ファイルを変換するか、Box AIが対応する形式一覧と照らし合わせて確認してください。
  </Accordion>
  <Accordion title="box_create_collaborationが権限不足エラーで失敗する">
    対象フォルダに適切なロールを持つユーザーのみが新しいコラボレーターを招待できます。再試行する前に、`box_get_collaboration`でリクエスト元アカウントのロールを確認してください。
  </Accordion>
  <Accordion title="大きなファイルでbox_upload_fileが失敗する">
    Boxはおおよそ20MBを超えるファイルにはチャンクアップロードを要求します。大きなファイルには`box_upload_file`ではなく、(先に`box_preflight_check`を行った上で)`box_chunked_upload`を使用してください。
  </Accordion>
</AccordionGroup>
