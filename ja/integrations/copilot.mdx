# GitHub Copilot

ShanoneのGitHub Copilot連携は、管理者/エンタープライズ向けのCopilot管理を扱う37個のツールをエージェントに提供します。シート、請求、利用状況メトリクス、カスタムエージェント、コンテンツ除外、Copilot Cloud Agentポリシーが対象です。

## はじめに

<Steps>
  <Step title="Fine-grained Personal Access Tokenを発行する">
    GitHubの**Settings → Developer settings → Fine-grained tokens**で、Copilot関連の組織権限を持つトークンを作成します。
  </Step>
  <Step title="Shanoneに登録する">
    Shanoneダッシュボードの**連携**を開き、GitHub Copilotを選択してトークンを貼り付けます。
  </Step>
  <Step title="リクエストを再実行する">
    保存が完了すると、`copilot_*`ツールに対する`shanone_execute_tool`呼び出しが成功するようになります。
  </Step>
</Steps>

## トラブルシューティング

<AccordionGroup>
  <Accordion title="エンタープライズ向けのツールが404を返す">
    `copilot_get_enterprise_*`や`copilot_*_enterprise_agent_*`系のツールは、GitHub Enterpriseアカウントに属する組織でのみ動作します。通常の組織の場合は代わりに`_org_`版のツールを使用してください。
  </Accordion>
  <Accordion title="copilot_add_usersやcopilot_add_teamsが権限エラーで失敗する">
    Copilotシートの管理には、トークンのアカウントに組織のオーナーまたはCopilot管理者権限が必要です。一般メンバーのトークンでは利用状況の読み取りはできますが、シート割り当ての変更はできません。
  </Accordion>
  <Accordion title="メトリクス系のツールが直近の日付について空の配列を返す">
    GitHub Copilotの利用状況メトリクスはおよそ1〜2日遅れで集計されます。ごく最近の活動は`copilot_get_org_metrics_daily`にまだ反映されていない可能性があります。
  </Accordion>
</AccordionGroup>
