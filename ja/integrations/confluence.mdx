# Confluence

ShanoneのConfluence連携は、Atlassian Confluenceを扱う46個のツールをエージェントに提供します。ページ、ブログ記事、コメント、ラベル、添付ファイル、スペース、タスク、検索が対象です。

## はじめに

<Steps>
  <Step title="Atlassian APIトークンを発行する">
    [Atlassian API tokens](https://id.atlassian.com/manage-profile/security/api-tokens)にアクセスし、アカウント用の新しいトークンを作成します。
  </Step>
  <Step title="認証情報をShanoneに登録する">
    Shanoneダッシュボードの**連携**を開き、Confluenceを選択して、AtlassianアカウントのメールアドレスとAPIトークンを入力します。
  </Step>
  <Step title="リクエストを再実行する">
    保存が完了すると、`confluence_*`ツールに対する`shanone_execute_tool`呼び出しが成功するようになります。
  </Step>
</Steps>

## トラブルシューティング

<AccordionGroup>
  <Accordion title="トークンは有効に見えるのにツールが401で失敗する">
    Confluence Cloudでは、トークン単体ではなくアカウントの**メールアドレス**とAPIトークンの組み合わせ(Basic認証)が必要です。連携ページの両方のフィールドが保存されているか確認してください。
  </Accordion>
  <Accordion title="confluence_create_pageが本文フォーマットのエラーで失敗する">
    Confluenceのページ本文は、APIバージョンによってAtlassian Document Format(ADF)またはstorage形式のXHTMLを使用します。リッチコンテンツを送信する前に、`confluence_create_page`について`shanone_get_tool_schema`でどちらの形式が期待されているか確認してください。
  </Accordion>
  <Accordion title="confluence_searchの結果が想定より少ない">
    `confluence_search`は内部でCQL(Confluence Query Language)を使用します。単純なキーワードでも動作しますが、スペース・ラベル・タイプなどで正確に絞り込むにはフリーテキストではなく適切なCQL式を組み立ててください。
  </Accordion>
</AccordionGroup>
