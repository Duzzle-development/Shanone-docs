# Cloudflare

ShanoneのCloudflare連携は、Cloudflareプラットフォームのほぼ全域を扱う247個のツールをエージェントに提供します。DNS、ゾーン、Workers、Pages、R2、D1、KV、キュー、Zero Trust Access、AI Gateway、Workers AI、ロードバランシング、セキュリティ/監査ツールが対象です。

## はじめに

<Steps>
  <Step title="APIトークンを作成する">
    Cloudflareダッシュボードの**My Profile → API Tokens**で、必要なZone/DNS/Workers/Pagesなどの権限を持つトークンを作成します(または、フルアクセス用のより広い権限のトークンでも構いません)。
  </Step>
  <Step title="Shanoneに登録する">
    Shanoneダッシュボードの**連携**を開き、Cloudflareを選択してAPIトークンとアカウントIDを入力します。
  </Step>
  <Step title="リクエストを再実行する">
    保存が完了すると、`cloudflare_*`ツールに対する`shanone_execute_tool`呼び出しが成功するようになります。
  </Step>
</Steps>

## トラブルシューティング

<AccordionGroup>
  <Accordion title="トークンは有効なのに「Authentication error」が返る">
    ほとんどのCloudflareツールにはAPIトークンとアカウントIDの両方が必要で(DNS/ゾーン系のツールにはさらに`zone_id`も必要)、必須フィールドは`shanone_get_tool_schema`で確認してください。アカウントスコープのリソースとゾーンスコープのリソースでは識別子が異なります。
  </Accordion>
  <Accordion title="cloudflare_d1_query / cloudflare_r2_*系のツールが権限エラーを返す">
    APIトークンはプロダクトごとにスコープが分かれています。DNS権限のみで作成したトークンではD1、R2、Workersのエンドポイントを呼び出せません。必要なスコープを追加した新しいトークンを作成するか、より広いアカウントレベルのトークンを使用してください。
  </Accordion>
  <Accordion title="作成したばかりのDNSレコードがまだ解決されない">
    DNSの変更はCloudflareのエッジネットワーク全体に伝播するため、API呼び出し自体は即座に成功していても反映には少し時間がかかります。これはツールの失敗ではなく想定された挙動です。
  </Accordion>
  <Accordion title="cloudflare_create_pages_deploymentが最新のコードを反映していない">
    Pagesのデプロイは、トリガー時にプッシュされたビルド/アーティファクトに紐づきます。新しいデプロイをトリガーする前に、Git連携または直接アップロードした内容に変更が実際に含まれているか確認してください。
  </Accordion>
</AccordionGroup>
