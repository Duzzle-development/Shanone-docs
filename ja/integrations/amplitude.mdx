# Amplitude

ShanoneのAmplitude連携では、分析クエリ、ユーザー/イベントのタクソノミー管理、コホート、アノテーション、プライバシー/削除リクエストをカバーする**62個のツール**をエージェントに提供します。

## はじめに

<Steps>
  <Step title="AmplitudeのAPI認証情報を取得する">
    Amplitudeでプロジェクトの**Settings > Projects**を開き、API KeyとSecret Keyをコピーします。
  </Step>
  <Step title="Shanoneで接続する">
    エージェントにAmplitudeで何か作業をしてもらう(例:「過去30日間のリテンション分析を見せて」)か、Shanoneダッシュボードの**インテグレーション**から両方のキーを事前に登録します。
  </Step>
  <Step title="リクエストを再試行する">
    両方のキーが保存されると、`amplitude_*`ツールに対する`shanone_execute_tool`の呼び出しが成功するようになります。
  </Step>
</Steps>

<Note>
AmplitudeはOAuthではなくAPIキー認証を使用し、ShanoneはAPI KeyとSecret Keyの両方を必要とします — ほとんどのエンドポイントがHTTP Basic認証でこのペアを要求します。
</Note>

## トラブルシューティング

<AccordionGroup>
  <Accordion title="amplitude_* の呼び出しが401/403で失敗する">
    Amplitudeでは API KeyとSecret Keyの両方の接続が必要です — ほとんどのエンドポイントは1つのキーだけでは動作しません。Shanoneダッシュボードの**インテグレーション**で両方の値を確認してください。
  </Accordion>
  <Accordion title="amplitude_get_funnel_analysisやamplitude_get_retention_analysisの結果が想定外に空になる">
    `amplitude_get_event_types`でイベント名を確認してください — Amplitudeのイベント名は大文字小文字を区別し、実際に取り込まれた名前と完全に一致させる必要があります。
  </Accordion>
  <Accordion title="amplitude_check_cohort_statusが保留状態のまま変わらない">
    コホートのダウンロードや同期はAmplitude側で非同期に処理されます。`amplitude_request_cohort_download`の即時レスポンスを期待するのではなく、`amplitude_check_cohort_status`を定期的にポーリングしてください。
  </Accordion>
</AccordionGroup>
