# Cursor

ShanoneのCursor連携は、Cursor自身のCloud Agents APIを操作する17個のツールをエージェントに提供します。エージェントの起動、実行の監視、フォローアップの送信、アーティファクトの取得が対象です。

## はじめに

<Steps>
  <Step title="Cursor APIキーを発行する">
    Cursorの[cursor.com/settings](https://www.cursor.com/settings)でAPIキーを作成します。
  </Step>
  <Step title="Shanoneに登録する">
    Shanoneダッシュボードの**連携**を開き、Cursorを選択してAPIキーを貼り付けます。
  </Step>
  <Step title="リクエストを再実行する">
    保存が完了すると、`cursor_*`ツールに対する`shanone_execute_tool`呼び出しが成功するようになります。
  </Step>
</Steps>

## 利用可能なツール

ShanoneはCursor向けに**17個のツール**を、以下のカテゴリに整理して提供しています。

<AccordionGroup>
  <Accordion title="Cloud Agent">
    `cursor_list_agents`, `cursor_get_agent_status`, `cursor_get_agent_conversation`, `cursor_launch_agent`, `cursor_add_followup`, `cursor_delete_agent`, `cursor_archive_agent`, `cursor_unarchive_agent`
  </Accordion>
  <Accordion title="Run">
    `cursor_list_runs`, `cursor_get_run`, `cursor_create_run`, `cursor_cancel_run`
  </Accordion>
  <Accordion title="アーティファクト">
    `cursor_list_artifacts`, `cursor_download_artifact`
  </Accordion>
  <Accordion title="アカウント情報">
    `cursor_get_api_key_info`, `cursor_list_models`, `cursor_list_repositories`
  </Accordion>
</AccordionGroup>

## トラブルシューティング

<AccordionGroup>
  <Accordion title="cursor_launch_agentがリポジトリアクセスエラーで失敗する">
    対象のリポジトリは、接続済みアカウントについて`cursor_list_repositories`に表示されている必要があります。Cursor Cloud AgentはAPIキーのアカウントが実際にアクセスできるリポジトリでのみ動作します。
  </Accordion>
  <Accordion title="cursor_get_agent_statusが実行中の状態から進まない">
    長時間実行のエージェントは数分かかることが想定されています。即座の完了を期待せず、`cursor_get_agent_status`を定期的にポーリングし、中間の進行状況は`cursor_get_agent_conversation`で確認してください。
  </Accordion>
  <Accordion title="cursor_add_followupが効果を持たない">
    フォローアップは、まだアクティブな(アーカイブ・削除されていない、または完了していない)エージェントにのみ送信できます。まず`cursor_get_agent_status`を確認し、エージェントが既に完了している場合は`cursor_launch_agent`で新規に起動してください。
  </Accordion>
</AccordionGroup>
