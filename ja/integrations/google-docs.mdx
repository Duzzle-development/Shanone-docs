# Google Docs

ShanoneのGoogle Docs連携は、コンテンツ・書式設定、テーブル、画像、コメント/提案、タブ、そして生のブロック操作よりもエージェントによる編集をはるかに便利にするMarkdown変換ツールまで、Docs APIの機能全体をカバーする58個のツールをエージェントに提供します。

## はじめに

<Steps>
  <Step title="OAuthで接続する">
    エージェントにGoogle Docs関連の作業を依頼(例: 「このアウトラインを整形されたドキュメントにして」)するか、Shanoneダッシュボードの**連携**から事前に接続しておきます。
  </Step>
  <Step title="Googleアカウントを許可する">
    Shanoneに操作させたいアカウントについて、GoogleのOAuth同意画面を承認します。
  </Step>
  <Step title="リクエストを再実行する">
    接続が完了すると、`google_docs_*`ツールに対する`shanone_execute_tool`呼び出しが成功するようになります。
  </Step>
</Steps>

## トラブルシューティング

<AccordionGroup>
  <Accordion title="google_docs_update_document_from_markdownで予期しない書式になる">
    Markdownコンバーターは一般的な要素(見出し、リスト、テーブル、太字/斜体)をサポートしていますが、Docsネイティブの機能すべてには対応していません。高度な書式設定が必要な場合は、特定の範囲に対して`google_docs_update_text_style`や`google_docs_update_paragraph_style`を後続で使用してください。
  </Accordion>
  <Accordion title="連続した複数の編集で変更が競合したり重複してしまう">
    インデックスベースの操作(挿入/削除)は以降のコンテンツのオフセットをずらします。関連する変更を行う際は、複数の単発編集呼び出しを連続させるより、複数のリクエストを含む単一の`google_docs_batch_update`呼び出しを優先してください。
  </Accordion>
  <Accordion title="google_docs_insert_commentや提案系のツールが効果を発揮していないように見える">
    コメントと提案はコンテンツの編集とは別物で、ファイルに対するDocsネイティブのコメント/提案権限が必要です。接続中のアカウントが少なくともコメント可能な権限を持っているか確認してください。
  </Accordion>
</AccordionGroup>
