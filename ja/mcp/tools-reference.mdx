## Tool Vendor

アクションごとに専用のMCPツールを用意することなく、Shanoneの269以上の連携を検索・確認・実行します。

**推奨ワークフロー:** `shanone_search_tools`(完全な一覧が必要な場合は`shanone_list_service_tools`) → `shanone_get_tool_schema`(必要な場合) → `shanone_execute_tool`。

### shanone_search_tools

キーワードで連携ツールを検索します(関連度でランク付け)。

<ParamField path="query" type="string" required>
  自然言語またはキーワードによる検索。例: `"post slack message"`、`"create github issue"`。
</ParamField>
<ParamField path="service" type="string">
  任意のサービスフィルター。例: `"slack"`、`"github"`、`"notion"`。
</ParamField>
<ParamField path="limit" type="integer" default="20">
  最大結果件数(最大100)。
</ParamField>
<ParamField path="offset" type="integer" default="0">
  ページネーション用に、スキップする一致結果の件数。
</ParamField>

<Tabs>
  <Tab title="Example Request">
    ```json
    { "query": "post slack message", "service": "slack", "limit": 5 }
    ```
  </Tab>
  <Tab title="Example Response">
    ```
    Showing 1 of 1 matching tool(s) for "post slack message" (service: slack) (offset=0):

    - **slack_post_message** (slack)
      Post a message to a Slack channel or user.

    **Next steps:**
    1. Use `shanone_get_tool_schema` to see the input schema for a tool
    2. Use `shanone_execute_tool` to execute the tool with arguments
    ```
  </Tab>
</Tabs>

<Note>
大規模な連携(Slackは125ツール、Stripeは328ツール)の場合、関連度ランキングではすべての一致結果が表示されないことがあります——`has_more`を確認し、trueであればクエリを絞り込むか、代わりに`shanone_list_service_tools`を使用してください。
</Note>

<ParamField path="service" type="string" required>
  正確なサービス名。例: `"slack"`、`"github"`、`"notion"`。
</ParamField>
<ParamField path="limit" type="integer" default="50">
  1ページあたりの最大結果件数(最大200)。
</ParamField>
<ParamField path="offset" type="integer" default="0">
  ページネーション用に、スキップする結果の件数。
</ParamField>

<Tabs>
  <Tab title="Example Request">
    ```json
    { "service": "linear", "limit": 50, "offset": 0 }
    ```
  </Tab>
  <Tab title="Example Response">
    ```
    linear: showing 45 of 45 tool(s) total (offset=0):

    - **linear_create_issue**
      Create a new issue in a Linear team.
    - **linear_list_issues**
      List issues, optionally filtered by team, assignee, or state.
    ... (43 more)

    **Next steps:**
    1. Use `shanone_get_tool_schema` to see the input schema for a tool
    2. Use `shanone_execute_tool` to execute the tool with arguments
    ```
  </Tab>
</Tabs>

### shanone_get_tool_schema

ツールの入力引数のJSON Schemaを取得します。

<ParamField path="tool_name" type="string" required>
  正確なツール名(例: `"slack_post_message"`)。`shanone_search_tools`または`shanone_list_service_tools`から取得してください。
</ParamField>

<Tabs>
  <Tab title="Example Request">
    ```json
    { "tool_name": "slack_post_message" }
    ```
  </Tab>
  <Tab title="Example Response">
    ```
    **slack_post_message**

    Post a message to a Slack channel or user.

    **Input Schema:**
    ```json
    {
      "type": "object",
      "properties": {
        "channel": { "type": "string", "description": "Channel name or ID, e.g. #general" },

      },

    **Required arguments:** channel, text

    **Next step:** Use `shanone_execute_tool` with tool_name="slack_post_message" and the required arguments.
    ```
  </Tab>
</Tabs>

### shanone_execute_tool

引数を指定してツールを実行します。OAuthは自動的に処理されます——ツールに未設定の接続が必要な場合、エラーで失敗する代わりに`connect_link`が返されます。

<ParamField path="tool_name" type="string" required>
  実行する正確なツール名。
</ParamField>
<ParamField path="arguments" type="string" required>
  **JSON文字列**としてのツール引数(ネイティブオブジェクトではありません)。例: `'{"channel": "#general", "text": "Hello!"}'`。引数のないツールには`'{}'`を渡してください。
</ParamField>
<ParamField path="session_id" type="string">
  ステートフルな複数ステップの実行のための任意のセッションID。ステートレスな呼び出しの場合は省略してください。
</ParamField>

<Tabs>
  <Tab title="Example Request">
    ```json
    {
      "tool_name": "slack_post_message",
      "arguments": "{\"channel\": \"#general\", \"text\": \"Hello from Cursor!\"}"
    }
    ```
  </Tab>
  <Tab title="Success">
    ```
    Tool: slack_post_message
    Duration: 412ms
    Session: tool_a1b2c3d4e5f6

    Result:
    { "ok": true, "message_ts": "1735282800.000100" }
    ```
  </Tab>
  <Tab title="Auth required">
    ```
    Authentication Required

    Tool: slack_post_message
    Service: slack
    Reason: auth_required
    Auth Type: oauth2

    Slack への接続が必要です。

    Connect Link: https://app.shanone.ai/connect/slack?request=req_abc123

    Please ask the user to visit the connect link to authenticate, then retry the request.
    ```
  </Tab>
  <Tab title="Confirmation required">
    ```
    Confirmation Required

    Tool: github_delete_repo
    Risk tier: destructive

    This action is irreversible. Please confirm you want to proceed.

    Ask the user to explicitly confirm this action. Once confirmed, call
    shanone_execute_tool again with the SAME arguments plus an additional
    "confirm": true field in the arguments JSON.
    ```
  </Tab>
</Tabs>

<Note>
`reason`が`auth_required`または`auth_expired`の場合は、`Connect Link`をユーザーに提示してください。ユーザーが認証を完了したら、まったく同じ`shanone_execute_tool`の呼び出しを再試行してください。
</Note>

## Skill Vendor

**Skill**とは、タスクの実行方法を記述した、名前付きの再利用可能なプロンプトです(`name` + `summary` + `instructions`)。Skillはサーバー側に保存されるため、マシン、IDE、エージェントを越えて再現可能であり、Shanoneのウェブダッシュボードの**Skills**にも表示されます。

**推奨ワークフロー:** タスクを始める前に`shanone_list_skills` → `shanone_get_skill`で読み込み、自分でその指示に従う。

### shanone_list_skills

保存済みのSkillを新しい順に一覧表示します。デフォルトでは**すべての**Skillを返します(ページ分割あり)——`query`は必須の検索語ではなく任意のフィルターです。

<ParamField path="query" type="string">
  名前/概要に対する任意のフィルター。すべてのSkillを返す場合は空のままにしてください。
</ParamField>
<ParamField path="limit" type="integer" default="20">1ページあたりの最大結果件数(最大100)。</ParamField>
<ParamField path="offset" type="integer" default="0">スキップする結果の件数。</ParamField>

<Tabs>
  <Tab title="Example Request">
    ```json
    { "query": "", "limit": 20, "offset": 0 }
    ```
  </Tab>
  <Tab title="Example Response">
    ```
    Showing 2 of 2 skill(s) (offset=0):

    - **Weekly Status Report** (skill_id: 3f1a9e2b-1234-4c56-9abc-1234567890ab)
      Gathers last week's closed issues and posts a summary to Slack #team.
    - **Daily Standup Reminder** (skill_id: 7c2b5f8d-5678-4d9e-bcde-234567890abc)
      Posts a standup reminder to Slack #general every weekday morning.

    **Next step:** Use `shanone_get_skill` with a skill_id to read the full instructions, then follow them.
    ```
  </Tab>
</Tabs>

## Permission Vendor

IAM形式のツール/サービスアクセス制御です。`shanone_list_services`は誰でも利用できますが、他の5つのツールを利用するには、呼び出し元が**Root**ユーザーであるか、`tool-permissions:ManageOthers`というポリシーアクションを明示的に委任された**SA2**ユーザーである必要があります(委任されたSA2の呼び出し元はRootユーザーを対象にすることはできません)。

### shanone_list_services

登録済みの全サービスを、表示名とツール数とともに一覧表示します。特別な権限は不要です。

<ParamField path="limit" type="integer" default="100">1ページあたりの最大結果件数(最大500)。</ParamField>
<ParamField path="offset" type="integer" default="0">スキップする結果の件数。</ParamField>

<Tabs>
  <Tab title="Example Response">
    ```
    Showing 3 of 269 service(s) (offset=0):

    - **slack** (Slack) - 125 tool(s)
    - **github** (GitHub) - 176 tool(s)
    - **notion** (Notion) - 45 tool(s)

    More services available. Call again with offset=3.

    **Next steps:** Use a `service_name` above with `shanone_set_user_service_permission`,
    `shanone_list_user_tool_permissions`, or `shanone_batch_set_user_permissions`.
    ```
  </Tab>
</Tabs>

### shanone_set_user_tool_permission

対象ユーザーに対して、特定の1ツールを有効/無効にします。サービスレベルのオーバーライドやロールのデフォルト設定よりも常に優先されます。

<ParamField path="target_user_id" type="string" required>変更対象のuser_id。</ParamField>
<ParamField path="tool_name" type="string" required>正確なツール名。</ParamField>
<ParamField path="enabled" type="boolean" required>許可する場合はtrue、拒否する場合はfalse。</ParamField>

対象ユーザーに対して、1つのサービスの全ツールを一度に有効/無効にします。

<ParamField path="target_user_id" type="string" required>変更対象のuser_id。</ParamField>

<ParamField path="enabled" type="boolean" required>このサービスの全ツールを許可する場合はtrue、拒否する場合はfalse。</ParamField>

### shanone_batch_set_user_permissions

対象ユーザーに対して、多数のサービスやツールを1回の呼び出しで有効/無効にします。最大500操作まで、個々の失敗があってもバッチ全体は中断されません。

<ParamField path="target_user_id" type="string" required>変更対象のuser_id。</ParamField>
<ParamField path="operations" type="string" required>
  `{"type": "service"|"tool", "name": "...", "enabled": true|false}`のJSON配列文字列。
</ParamField>

<Tabs>
  <Tab title="Example Request">
    ```json
    {
      "target_user_id": "usr_123",
      "operations": "[{\"type\": \"service\", \"name\": \"slack\", \"enabled\": true}, {\"type\": \"service\", \"name\": \"stripe\", \"enabled\": false}]"
    }
    ```
  </Tab>
  <Tab title="Example Response">
    ```
    Applied 2 update(s) for user usr_123:

    - service 'slack' -> enabled
    - service 'stripe' -> disabled
    ```
  </Tab>
</Tabs>

## エラーレスポンス

| 状況 | レスポンス |
|-----------|----------|
| 不明なツール名 | `Tool not found: <tool_name>`、`shanone_search_tools`の利用を促すヒント付き |
| 不明な`skill_id` | `Skill not found: <skill_id>`、`shanone_list_skills`の利用を促すヒント付き |
| `shanone_execute_tool`の`arguments`内のJSONが不正 | `Invalid JSON in arguments: ...`、期待される形式とともに |
| 連携にOAuthが必要だが未接続 | `reason: "auth_required"`(または`"auth_expired"`)と`connect_link` |
| リスクの高いアクションに明示的な確認が必要 | `reason: "confirmation_required"`；`"confirm": true`を付けて再試行 |
| 呼び出し元にPermission Vendorツールの権限がない | `Permission Denied`——呼び出し元はRoot、または`tool-permissions:ManageOthers`を委任されたSA2である必要があります |
| HTTPレベルの認証失敗(不正/欠落したAPIキー) | `401`、`error: "api_key_required"`または`"invalid_api_key"` |
| 組織IDの欠落/不正(直接`/mcp`接続のみ) | `401 org_id_required`または`403 invalid_org_id` |
| リクエストが多すぎる | `429`、`error: "rate_limit_exceeded"`と`Retry-After`ヘッダー |
