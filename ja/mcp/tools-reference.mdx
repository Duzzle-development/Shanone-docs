Remote MCP の29ツールについて、引数・プラン・課金・利用回数の扱いを説明します。

このリファレンスは **Remote MCP（Streamable HTTP）** を対象とします。ローカルプロキシの公開ツールや引数形式はパッケージ・バージョンにより異なります。実際の一覧は接続先の `tools/list` で確認してください。

以下のプラン表は契約上の利用可否です。API キーの権限、ユーザーの権限、対象リソースへのアクセス許可、外部サービスへの接続も必要です。プランだけで権限が付与されるわけではありません。

「課金対象」はプランの Tool Call 利用枠を消費する意味で、呼び出しごとの追加請求を意味しません。管理ツールと接続診断は非課金です。スキル13ツールは Plus 以上で利用でき、成功した呼び出しだけが１回分を消費します。

スキルツールは Free にも名前・説明・入力スキーマを公開します。Free からの実行は、スキルデータにアクセスする前に `PLAN_UPGRADE_REQUIRED` で拒否します。再ログインでは解消しません。

応答はツールにより Markdown テキスト、JSON を含むテキスト、構造化エラーを返します。スキルのプラン拒否・操作失敗は MCP の `isError: true` で返ります。実行ツールでは JSON 内の `status`、`success`、`reason` と外部サービスの結果も確認してください。

## 接続管理

### shanone_list_connections

呼出元が参照できる保存済み接続を一覧表示します。登録済みであることは、認証が現在も有効であることを意味しません。

| 引数 | 型 | 必須 / 既定値 | 説明 |
|---|---|---|---|
| `service` | string | `""` | gmail、slack などの正確なサービス識別子。 |

```json
{
  "service": "gmail"
}
```

`supports_account_selection: true` の ID だけを execute_tool に渡せます。現在の複数アカウント選択は Gmail が対象です。`legacy:<service>` は単一接続の診断用 ID で、check_connection には使えますが通常実行の接続指定には使えません。API キーには `integrations:read`（または `all`）が必要です。

### shanone_check_connection

読み取り専用の外部 API を使い、保存済み接続の有効性を確認します。service を省略すると、接続済みサービスをページ単位で確認します。

| 引数 | 型 | 必須 / 既定値 | 説明 |
|---|---|---|---|
| `service` | string | `""` | gmail、slack などの正確なサービス識別子。 |
| `connection_id` | string | `""` | 保存済み接続の識別子。 |
| `offset` | integer | `0` | 先頭からスキップする件数。 |
| `limit` | integer | `10` | １ページあたりの最大件数。 最大20件。 |

```json
{
  "service": "gmail",
  "offset": 0,
  "limit": 10
}
```

`connection_id` で１接続に絞れます。最大20件、同時検証３件、各検証の期限は30秒です。API キーには `integrations:read` と `tasks:create`（または `all`）が必要で、対象ツールの権限確認も行います。

主な結果: `verified`、`reauth_required`、`insufficient_permissions`、`permission_denied`、`rate_limited`、`temporarily_unavailable`、`verification_failed`、`unsupported`、`not_connected`。`verified` は指定された読み取り API の成功を意味し、全操作・全権限の保証ではありません。未対応サービスは `unsupported` と返し、成功として扱いません。

## ツール実行

### shanone_execute_tool

連携ツールを実行します。実行結果の外側のステータスと外部サービスの結果を確認してください。呼び出しの完了だけで業務処理の成功とは判断しません。

| 引数 | 型 | 必須 / 既定値 | 説明 |
|---|---|---|---|
| `tool_name` | string | 必須 | gmail_get_profile などの正確なツール名。 |
| `arguments` | string | 必須 | 連携ツールへの引数を JSON 文字列で指定します。引数なしは "{}" です。 |
| `session_id` | string | `""` | 任意の既存実行・セッション識別子。OAuth アカウントの選択には使いません。状態を持たない呼び出しでは省略します。 |
| `connection_id` | string | `""` | Gmail の実行には必須。supports_account_selection が true の接続 ID を指定します。 |
| `request_id` | string | `""` | 任意の再試行識別子。同一の操作・引数・アカウントの再試行に限って再利用し、別の操作には使い回さないでください。 |

```json
{
  "tool_name": "gmail_get_profile",
  "arguments": "{}",
  "connection_id": "conn_example"
}
```

Gmail は先に list_connections で接続 ID を取得し、呼び出しごとに明示します。省略すると `CONNECTION_SELECTION_REQUIRED` を返します。別アカウントへの切替は次の呼び出しで ID を変更するだけです。`execution_context_id` は受け付けません。

`auth_required` / `auth_expired` の場合は返された接続案内に従います。`confirmation_required` の場合は操作の確認を得てから、同じ引数に `"confirm": true` を加えて再実行します。通常の実行は実行先ツール名で記録し、execute_tool 自体を追加で課金・集計しません。

## Skill Vendor

13ツールすべて Plus 以上・成功時のみ課金です。スキルやファイルの所有者・共有権限の確認も適用されます。

### shanone_list_skills

保存済みスキルを新しい順に一覧表示します。query は任意で、空の場合は対象の保存済みスキルをページ単位で取得します。

| 引数 | 型 | 必須 / 既定値 | 説明 |
|---|---|---|---|
| `query` | string | `""` | 検索文字列。任意項目の場合は空文字で省略できます。 |
| `limit` | integer | `20` | １ページあたりの最大件数。 最大100件。 |
| `offset` | integer | `0` | 先頭からスキップする件数。 |

### shanone_get_skill

スキルの名前、説明、指示本文を取得します。指示の実行は呼出元のエージェントが行い、この呼び出し自体がワークフローを実行するわけではありません。

| 引数 | 型 | 必須 / 既定値 | 説明 |
|---|---|---|---|
| `skill_id` | string | 必須 | list_skills または create_skill で取得した正確なスキル ID。 |

### shanone_create_skill

再利用可能なスキルを作成します。３項目すべてに空でない値が必要です。description と body は summary と instructions として保存されます。

| 引数 | 型 | 必須 / 既定値 | 説明 |
|---|---|---|---|
| `name` | string | 必須 | スキル名。 |
| `description` | string | 必須 | スキルの用途と利用する場面。 |
| `body` | string | 必須 | スキルの指示本文。 |

```json
{
  "name": "Weekly report",
  "description": "Prepare a weekly status report.",
  "body": "Read the relevant issues and summarize the completed work."
}
```

### shanone_update_skill

既存スキルを更新します。任意項目は空でない値だけを更新し、空文字の場合は既存の値を保持します。

| 引数 | 型 | 必須 / 既定値 | 説明 |
|---|---|---|---|
| `skill_id` | string | 必須 | list_skills または create_skill で取得した正確なスキル ID。 |
| `name` | string | `""` | スキル名。 |
| `summary` | string | `""` | 更新後のスキル説明。 |
| `instructions` | string | `""` | 更新後のスキル指示本文。 |

### shanone_delete_skill

スキルを完全に削除します。

| 引数 | 型 | 必須 / 既定値 | 説明 |
|---|---|---|---|
| `skill_id` | string | 必須 | list_skills または create_skill で取得した正確なスキル ID。 |

### shanone_list_skill_files

スキルに付属する追加ファイルのパスやサイズを一覧表示します。指示本文は get_skill で取得します。

| `skill_id` | string | 必須 | list_skills または create_skill で取得した正確なスキル ID。 |

### shanone_read_skill_file

### shanone_write_skill_file

UTF-8 テキストファイルを作成、または上書きします。親フォルダーがなければ自動作成します。

| 引数 | 型 | 必須 / 既定値 | 説明 |
|---|---|---|---|
| `skill_id` | string | 必須 | list_skills または create_skill で取得した正確なスキル ID。 |
| `path` | string | 必須 | references/guide.md など、スキルディレクトリからの相対パス。 |
| `content` | string | 必須 | 書き込む UTF-8 テキスト全文。既存の内容は置き換えます。 |


### shanone_delete_skill_file

### shanone_grep_skill

正規表現でスキルファイルを検索します。結果にはパスと行番号が含まれます。打ち切られた場合は検索条件を絞ってください。

| 引数 | 型 | 必須 / 既定値 | 説明 |
|---|---|---|---|

```json
  "path_glob": "references/*.md"
```

| `target_user_id` | string | 必須 | 権限を確認・変更する対象ユーザーの ID。 |

### shanone_batch_set_user_permissions

最大500件のサービス・ツール権限操作をまとめて適用します。１件の失敗で全体は中断しないため、各操作の結果を確認してください。

| 引数 | 型 | 必須 / 既定値 | 説明 |
|---|---|---|---|
| `target_user_id` | string | 必須 | 権限を確認・変更する対象ユーザーの ID。 |
| `operations` | string | 必須 | type（service または tool）、name、enabled を持つ空でない JSON 配列文字列。最大500件。 |

```json
{
  "target_user_id": "user_example",
  "operations": "[{\"type\":\"service\",\"name\":\"slack\",\"enabled\":true}]"
}
```

## パラメーターポリシー

### shanone_get_tool_parameter_policy

対象ユーザーのツールに設定された引数制約を取得します。ツールの利用可否と、許可する引数の値は別の制御です。

| 引数 | 型 | 必須 / 既定値 | 説明 |
|---|---|---|---|
| `target_user_id` | string | 必須 | 権限を確認・変更する対象ユーザーの ID。 |
| `tool_name` | string | 必須 | gmail_get_profile などの正確なツール名。 |

### shanone_set_tool_parameter_policy

１つの引数フィールドの制約を設定・置換します。制約は実行時にサーバー側で適用されます。

| 引数 | 型 | 必須 / 既定値 | 説明 |
|---|---|---|---|
| `target_user_id` | string | 必須 | 権限を確認・変更する対象ユーザーの ID。 |
| `tool_name` | string | 必須 | gmail_get_profile などの正確なツール名。 |
| `field_name` | string | 必須 | 制約を設定・取得・削除する正確な入力パラメーター名。 |
| `policy_type` | string | 必須 | 後述するポリシー種別のいずれか。 |
| `policy_value` | string | `"{}"` | ポリシーの設定を JSON オブジェクト文字列で指定します。後述の一覧を参照してください。 |

```json
{
  "target_user_id": "user_example",
  "tool_name": "gmail_send_message",
  "field_name": "to",
  "policy_type": "domain_allowlist",
  "policy_value": "{\"values\":[\"example.com\"]}"
}
```

| policy_type | policy_value の例（JSON 文字列の内容） | 意味 |
|---|---|---|
| `allowlist / denylist` | `{"values":["a","b"]}` | 指定した値を許可・拒否。 |
| `domain_allowlist` | `{"values":["example.com"]}` | ドメインを制限。 |
| `pattern` | `{"value":"^[A-Z].*"}` | 正規表現への一致を要求。 |
| `range` | `{"min":0,"max":100}` | 数値の範囲を制限。 |
| `max_length / max_items` | `{"value":200}` | 文字数・要素数を制限。 |
| `forced_value` | `{"value":"audit@example.com"}` | 値を常に上書き。 |
| `forced_append` | `{"value":"audit@example.com"}` | 設定した値を追加。 |
| `default_value` | `{"value":"user"}` | 省略された場合だけ補完。 |
| `required_override` | `{}` | フィールドを必須にする。 |

### shanone_delete_tool_parameter_policy

１つの引数フィールドの制約を削除します。ツール自体の許可・拒否設定は変更しません。

| 引数 | 型 | 必須 / 既定値 | 説明 |
|---|---|---|---|
| `target_user_id` | string | 必須 | 権限を確認・変更する対象ユーザーの ID。 |
| `tool_name` | string | 必須 | gmail_get_profile などの正確なツール名。 |
| `field_name` | string | 必須 | 制約を設定・取得・削除する正確な入力パラメーター名。 |

## エラーと移行

| 結果 | 対処 |
|---|---|
| `PLAN_UPGRADE_REQUIRED` | Plus 以上のプランが必要です。拒否された呼び出しは非課金です。 |
| `TOOL_CALL_LIMIT_EXCEEDED` | 利用枠を確認します。スキルの操作は実行されず非課金です。 |
| `SUBSCRIPTION_UNAVAILABLE` | 契約情報を確認できません。時間をおいて再試行します。 |
| `CONNECTION_SELECTION_REQUIRED` | list_connections で取得した Gmail 接続 ID を明示します。 |
| `CONNECTION_NOT_FOUND` / `connection_not_found` | 接続の所有者・存在を確認します。別アカウントへの自動フォールバックはしません。 |
| `401` / `403` | API キー、組織 ID、必要な権限を確認します。MCP のプラン拒否とは区別してください。 |

`shanone_create_execution_context`、`shanone_get_execution_context`、`shanone_switch_connection` は廃止されました。クライアントのツール一覧を再取得し、接続 ID の明示指定へ移行してください。

Analytics を取得する `shanone_get_tool_usage` は設計段階で、公開済みツールには含まれません。

[接続設定を見る](/ja/mcp/setup)。
