Shanone MCPサーバーは、Cursor、Claude Code、Codexなど、MCP対応のあらゆるクライアントに、Shanoneの連携エコシステム、Skillライブラリ、そして(管理者であれば)権限管理へのプログラムによるアクセスを提供します。しかも、数百個の個別の連携アクションをエージェントのコンテキストウィンドウにさらすことはありません。

## 利用可能なツール

Shanoneは**18個のツール**を、4つのグループに分けて公開しています。

### Health Check(1ツール)

| ツール | 説明 |
|------|-------------|
| `shanone_health_check` | 接続性、APIキーの有効性、バックエンドの健全性を確認します。プレーンテキストのステータス画面を返します。 |

### Tool Vendor(4ツール)

| ツール | 説明 |
|------|-------------|
| `shanone_search_tools` | キーワードで連携カタログを検索します(関連度でランク付け) |
| `shanone_list_service_tools` | 1つのサービスの全ツールを名前順に列挙します(完全な一覧が必要な場合) |
| `shanone_get_tool_schema` | ツールの入力JSON Schemaを取得します |
| `shanone_execute_tool` | 引数を指定してツールを実行します。OAuthが必要な場合は`connect_link`を返します |

### Skill Vendor(5ツール)

| ツール | 説明 |
|------|-------------|
| `shanone_list_skills` | 保存済みのSkill(メタデータのみ)を新しい順に一覧表示します |
| `shanone_get_skill` | Skillの完全な指示内容を取得します |
| `shanone_create_skill` | 新しい再利用可能なSkillを保存します |
| `shanone_update_skill` | 既存のSkillの名前/概要/指示内容を更新します |
| `shanone_delete_skill` | Skillを完全に削除します |

### Permission Vendor(6ツール——最初の1つを除き、RootまたはSA2委任ユーザーのみ)

| ツール | 説明 |
|------|-------------|
| `shanone_list_services` | 登録済みの全サービスをツール数とともに一覧表示します(特別な権限は不要) |
| `shanone_list_user_tool_permissions` | 対象ユーザーの権限オーバーライドを一覧表示します |
| `shanone_set_user_tool_permission` | 対象ユーザーに対して特定の1ツールを有効/無効にします |
| `shanone_set_user_service_permission` | 対象ユーザーに対してあるサービスの全ツールを有効/無効にします |
| `shanone_get_permission_summary` | 対象ユーザーの有効/無効なアクセス数の集計を取得します |
| `shanone_batch_set_user_permissions` | 対象ユーザーに対して、最大500件のサービス/ツール操作を一度に適用します |

<Note>
すべてのツールの完全なパラメータ、レスポンス形式、例については、[ツールリファレンス](/ja/mcp/tools-reference)を参照してください。
</Note>

## 認証

Shanone MCPサーバーの利用にはAPIキーが必要です。Shanoneダッシュボードの**Settings → API Keys**から取得できます——キーは1度だけ`sh_xxxxxxxxxxxxxxxx`という形式で表示されます。

すべてのリクエストで`Authorization: Bearer <api_key>`(または`X-API-Key: <api_key>`)として送信してください。(ローカルstdioプロキシ経由ではなく)リモートエンドポイントに直接接続する場合は、組織ID(organization ID)も`X-Org-Id`として必要です——正確なクライアント設定については[セットアップ](/ja/mcp/setup)を参照してください。

<Warning>
APIキーは安全に管理してください。バージョン管理にコミットしたり、公開して共有したりしないでください。
</Warning>

## 推奨ワークフロー

### Tool Vendor: 検索 → スキーマ確認 → 実行

<Steps>
  <Step title="ツールを検索する">
    タスクの内容を表す自然言語のクエリで`shanone_search_tools`を呼び出します(必要に応じて`service`で絞り込み可能)。
  </Step>
  <Step title="必要ならスキーマを確認する">
    正確なツール名で`shanone_get_tool_schema`を呼び出し、必須・任意の引数を確認します。
  </Step>
  <Step title="実行する">
    ツール名と引数のJSON文字列で`shanone_execute_tool`を呼び出します。対象サービスに未設定の認証が必要な場合、レスポンスには`connect_link`が含まれます——それにアクセスしてから再試行してください。
  </Step>
</Steps>

### Skill Vendor: 一覧 → 取得 → 実行 → 保存

<Steps>
  <Step title="既存のSkillを確認する">
    タスクを始める前に`shanone_list_skills`を呼び出します——保存済みのSkillをすべて(任意で`query`で絞り込み可能)、ページ分割して返します。
  </Step>
  <Step title="指示内容を読む">
    `skill_id`を指定して`shanone_get_skill`を呼び出し、完全なステップバイステップの指示内容を取得します。
  </Step>
  <Step title="指示に従う">
    エージェント自身がその手順を実行し、連携アクションが必要な箇所では`shanone_search_tools` / `shanone_execute_tool`を使用します。
  </Step>
  <Step title="新しいワークフローを保存する">
    再利用する価値のあるワークフローを構築したら、`shanone_create_skill`を呼び出しておけば、後で別のマシンやエージェントからでも利用できます。
  </Step>
</Steps>

### Permission Vendor: チーム管理者向け

<Steps>
  <Step title="サービス名を確認する">
    `shanone_list_services`を呼び出し(特別な権限は不要)、正確な`service_name`の値を取得します。
  </Step>
  <Step title="オーバーライドを適用する">
    1件の変更であれば`shanone_set_user_service_permission` / `shanone_set_user_tool_permission`を、まとめて多数の変更を行うなら`shanone_batch_set_user_permissions`を呼び出します。
  </Step>
  <Step title="確認する">
    同じユーザーに対して`shanone_get_permission_summary`を呼び出し、変更が意図どおりに反映されたことを確認します。
  </Step>
</Steps>

## 利用例

### IDEから連携を見つけて使う

```
"Post 'Deploy finished' to Slack #general"
"Create a GitHub issue titled 'Fix login redirect bug' in owner/repo"
"Search for tools related to Notion"
```

エージェントは`shanone_search_tools`を呼び出し、続いて`shanone_execute_tool`を呼び出します(引数が不明な場合はまずスキーマを取得します)。

### タスクの途中で認証を処理する

```
"Send a message to my team on Slack"
```

Slackがまだ接続されていない場合、`shanone_execute_tool`は`success: false`と`reason: "auth_required"`、そして`connect_link`を返します。エージェントはそのリンクを提示し、認証が完了するのを待ってから、同じ呼び出しを再試行してください。

### ワークフローをSkillとして保存し再利用する

```
"Save this as a skill called 'Weekly Status Report'"
"List my saved skills"
"Run my 'Weekly Status Report' skill"
```

この方法で作成されたSkillは、Shanoneのウェブダッシュボードの**Skills**にも表示されます。
