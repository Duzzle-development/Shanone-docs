Remote MCP は **29ツール**を公開します。内訳はヘルスチェック１、検索・スキーマ・実行４、接続管理２、スキル13、サービス・権限管理９です。

プランとは別に、API キー・ユーザー・リソースの権限を確認します。権限の変更・他ユーザーの権限参照には Root または委任された SA2 権限が必要です。

## 推奨する使い方

1. **外部ツール:** search_tools（inputSchema同梱）→ execute_tool。schemaRef の場合や list_service_tools の後に必要な場合のみ get_tool_schema を呼びます。
2. **Gmail のアカウント選択:** list_connections → 必要に応じて check_connection → connection_id を明示して execute_tool。
3. **スキル（Plus 以上）:** list_skills → get_skill → エージェントが指示に沿って実行。追加ファイルも一覧・読み取り・検索できます。
4. **管理操作:** list_services → 権限・引数制約の設定 → get_permission_summary などで確認。

## 集計と利用枠

管理操作は非課金でも Analytics に記録されます。スキルは成功時だけ１回分を消費します。接続確認は内部の確認用 API を含めて非課金で、親１回だけを集計します。外部ツールの実行は実行先の通常の課金ルールに従います。
