---

Shanone は Model Context Protocol（MCP）を通じて、AI クライアントから外部サービス、保存したスキル、権限管理を利用できるようにします。Remote MCP は **29 ツール**を公開しています。

## 必要なツールを探して実行する

外部サービスの API をすべて MCP ツールとして並べる代わりに、次の順で必要な操作を見つけます。

1. `shanone_search_tools` または `shanone_list_service_tools` で操作を探す。
2. `shanone_get_tool_schema` で入力パラメーターを確認する。
3. `shanone_execute_tool` にツール名と引数を渡して実行する。

サービス側の OAuth 認証が必要な場合は、実行結果の接続案内に従います。Gmail では `shanone_list_connections` でアカウントを選び、実行時に `connection_id` を明示します。保存済みの接続が現在も有効かどうかは、`shanone_check_connection` で確認できます。

## 接続方式

| 方式 | 特徴 |
|---|---|
| Remote MCP（Streamable HTTP） | `https://mcp.shanone.ai/mcp` に接続します。このドキュメントの 29 ツールとパラメーターはこの方式を対象にしています。 |
| ローカル stdio プロキシ | npm の `@duzzle/shanone-mcp` または Python の `shanone-mcp` を起動し、Shanone の REST API に転送します。公開ツールと引数形式はパッケージ・バージョンによって異なります。 |

全 29 ツールを使う場合は Remote MCP を利用してください。接続先が実際に公開しているツールは MCP の `tools/list` で確認できます。例えば `shanone_execute_tool.arguments` は Remote MCP では JSON 文字列、Node.js プロキシではオブジェクトです。

## 認証とアクセス制御

Remote MCP には API キー（`Authorization: Bearer sh_...`、または `X-API-Key`）と組織 ID（`X-Org-Id`、または `org_id` クエリパラメーター）を渡します。組織 ID はアクセス対象の組織を指定する識別子です。ローカルプロキシでは `SHANONE_API_KEY` を設定します。

プランで利用できる機能でも、API キーのスコープ、ユーザー権限、対象リソースへのアクセス権、外部サービスの接続が必要です。他ユーザーの権限管理には Root または委譲された SA2 の権限が必要です。

## ツールの分類と課金

| 分類 | 件数 | 利用プラン | Tool Call の消費 |
|---|---|---|---|
| ヘルスチェック | 1 | Free 以上 | 非課金 |
| 外部ツールの検索・一覧・スキーマ | 3 | Free 以上 | 非課金 |
| 外部ツールの実行 | 1 | Free 以上 | 実行した外部ツールの課金ルールに従う |
| 接続一覧・接続確認 | 2 | Free 以上 | 非課金 |
| スキル・ファイル・フォルダー操作 | 13 | Plus / Pro / Team / Enterprise | 成功時に 1 回 |
| サービス一覧・権限管理・引数ポリシー | 9 | Free 以上 | 非課金 |

Free でもスキル 13 ツールの名前・説明・入力スキーマは表示されます。実行時にはサーバーがプランを確認し、Free の場合はスキルデータにアクセスする前に `PLAN_UPGRADE_REQUIRED` を返します。

非課金ツールも Analytics の利用回数に集計されます。接続確認は内部の API 確認回数ではなく、親の呼び出し 1 回として集計します。外部ツール実行は実際のツール名で集計し、`shanone_execute_tool` を別途加算しません。「課金対象」はプランの Tool Call 枠を消費する意味で、必ず追加料金が発生するという意味ではありません。
