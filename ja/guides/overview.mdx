## このガイド群が前提としていること

すでにShanoneを少なくとも1つのMCPクライアント(Cursor、Claude Codeなど)に接続済みであることを前提としています——まだの場合は[クイックスタート](/ja/quickstart)から始めてください。以降の内容はすべて、接続が済んだ後にShanoneを*効果的に使う*方法についてのものであり、最初の接続方法については触れません。

## メンタルモデル

Shanoneはエージェントに巨大な静的ツールリストを渡すわけではありません。渡すのは一握りの**メタツール**であり、これらが269以上のインテグレーションからなる生きたカタログを検索し、該当するツールを実行します。

| メタツール | 目的 |
|-----------|---------|
| `shanone_search_tools` | ツール名ではなくタスクの説明から、適切なツールを見つける |
| `shanone_list_service_tools` | 1つのサービスの全ツールを列挙する(「Xで何ができるか」という質問向け) |
| `shanone_get_tool_schema` | 呼び出す前に、そのツールが要求する引数を正確に確認する |
| `shanone_execute_tool` | 実際に実行する。OAuthは`connect_link`により自動的に処理される |
| `shanone_list_skills` / `shanone_get_skill` | 車輪の再発明をする前に、保存済みの再利用可能なワークフローがあるか確認して読む |

[ベストプラクティス](/ja/guides/best-practices)にあるアドバイスの大半は、実質的には最初の`shanone_search_tools`呼び出しで正しいツールを選ばせるための十分な手がかりをエージェントに与えることに関するものであり、当てずっぽうで再試行を繰り返すことを避けるためのものです。
